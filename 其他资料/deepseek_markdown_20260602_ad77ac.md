## 使用说明

1. 将 `{num}`、`{value}`、`{percent}` 替换为实际数据。
2. 较上周列使用：
   - `▲` 表示上升
   - `▼` 表示下降
   - `—` 表示持平
3. 变化率计算公式：
   - 如果本期 ≥ 上期：`(本期 - 上期) / 上期`
   - 如果本期 < 上期：`(上期 - 本期) / 上期`
4. 附录1、附录2、附录3 可单独附在周报末尾，用于详细分析TOP问题、工单趋势等。
