# 璧山小额工程馆-竞价的不定价订单支持前置抽佣

# 需求分析

## 需求背景

实例名称：璧山小额工程馆

实例编码：BSXEGC

以上实例竞价业务不定价订单比如：下浮率、费率项目，由竞价侧根据竞价预算和“璧山小额工程馆”竞价摇号出来的费率进行计算，计算完成后金额传递给订单侧，进行前置抽佣；

# 需求设计

## 需求说明

*   整体业务流程：
    
    *   在创建订单时，读取配置；如果命中，则生成定价订单，金额 = 预算 ×（1-下浮率）
        
*   业务影响范围
    
    *   业务类型：竞价
        
    *   实例区划：璧山小额工程馆
        
    *   交付环境：乐采云
        

## 详细设计

| **序号** | **功能** | **原型** | **说明** |
| --- | --- | --- | --- |
| 1 | 配置 | apollo 配置：**百分比报价创建定价订单**，实例级 |  |
| 2 | 业务逻辑 | *   在创建订单时，读取配置；如果命中，则生成定价订单。<br>    <br>    *   金额 = 预算 ×（1-优惠率）<br>        <br>    *   金额 = 预算 × 折扣率 |  |
| 3 | 注意 | 该模式要求：<br>*   预算确定，如果预算不确定，按照原不定价订单逻辑处理<br>    <br>*   预算金额 按照 需求商品金额的总和计算 |  |
