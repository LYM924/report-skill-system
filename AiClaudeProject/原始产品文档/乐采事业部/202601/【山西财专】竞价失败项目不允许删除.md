# 【山西财专】竞价失败项目不允许删除

# 需求分析

## 需求背景

竞价项目的**全生命周期数据留存**是采购合规审计、供应商绩效评估、采购策略优化的核心基础。其中，竞价失败项目（包括流标、废标、供应商不足法定数量、评审未通过等情形）承载着关键的业务信息与决策依据，例如失败原因、参与供应商名单、报价数据、评审意见、商务 / 技术要求匹配度等。
