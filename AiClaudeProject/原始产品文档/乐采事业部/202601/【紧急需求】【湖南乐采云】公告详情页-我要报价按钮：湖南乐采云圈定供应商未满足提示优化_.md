# 【紧急需求】【湖南乐采云】公告详情页-我要报价按钮：湖南乐采云圈定供应商未满足提示优化

# 一、需求背景

*   **背景：**湖南乐采云三个实例早期由于项目起步，基于快速业务拓展和交易引进，关于竞价的供应商范围选择的是正式供应商即可报价，但是在26年1月1日基于抽佣账单风险和违约风险考虑，项目运行平稳的情况，圈定的供应商范围调整为协议供应商。
    
*   **问题：**目前较多供应商反馈在公告大厅页面报价时提示：「当前竞价仅限【实例名称】供应商可参与报价，您不符合本次竟价供应商圈定要求。」后续供应商不清楚如何操作，需要运营介入或客服介入，无法线上自行完成闭环。
    
*   **需求链接：**[https://ipaas.cai-inc.com/dashboard/requirements-platform-index/demand/detail/?storyId=266450&bizType=STORY](https://ipaas.cai-inc.com/dashboard/requirements-platform-index/demand/detail/?storyId=266450&bizType=STORY)
    

# 二、需求内容

*   **适用范围：**云真线、乐采云
    
*   需求内容：将非圈定供应商报价提示配置及生效样式一并作为与公告页-报价按钮逻辑，在公告详情-我要报价按钮进行复用。
