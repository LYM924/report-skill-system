# 军采竞价单采购人联系方式格式优化需求

## 概览
针对竞价单中采购人联系方式因格式限制导致虚拟号拨打失败的问题，文章提出优化方案：采用“宽输入、准识别、分级校验”策略，允许包含姓名、备注的非标准输入，通过正则规则识别有效号码，确保系统兼容性与数据可用性。
关键要点包括：
1. 问题根源定位采购人联系方式仅输入10位号码导致虚拟号拨打失败，暴露现有校验规则对非纯手机号格式支持不足。
2. 多样化输入支持系统需兼容带区号、座机、分机、400/800电话及附带联系人或备注的混合文本输入，提升用户填写自由度。
3. 有效号码识别机制校验核心在于从完整文本中识别至少一个有效手机号、座机号或服务电话，而非要求整字段为标准号码格式。
4. 输入标准化处理校验前进行轻量预处理（如全角转半角、统一横线），但保留原始内容存储，兼顾识别准确性与信息完整性。
5. 分级校验与提示若未识别到有效号码则提示“未识别到有效手机号或座机号，请检查联系方式”，避免严格格式拦截合理输入。
---

## 1. 背景

平台多个业务场景中都需要用户填写联系方式，供后续业务沟通、平台运营或履约相关人员联系使用。

该字段后续还会用于**虚拟号拨打功能**。当前虚拟号模块直接取“联系方式”字段作为被叫号码，如果字段中包含联系人姓名、联系时间、备注等非联系方式内容，例如 `张三 13800138000 工作日8点-18点`，虚拟号模块可能无法识别真实号码，导致电话拨打失败。

为保证虚拟号拨打稳定，联系方式字段仅允许填写一个纯联系方式，不允许填写姓名、联系时间、备注等其他信息。允许的联系方式包括手机号、座机号、400/800 电话等。

| 类型 | 示例 |
| --- | --- |
| 纯手机号 | `13800138000` |
| 区号 + 手机号 | `+86 13800138000`、`86-13800138000` |
| 座机号码 | `010-88888888`、`0571 88888888` |
| 400 / 800 电话 | `400-123-4567`、`800 123 4567` |

---

## 2. 当前问题

当前平台对联系方式缺少有效格式校验和标准化能力，导致以下问题：

1.  用户可提交明显错误或不可拨打的联系方式；
    
2.  用户可在联系方式字段中填写姓名、备注、联系时间等非联系方式内容；
    
3.  拨打方通过虚拟号联系对方时，因号码格式异常导致无法接通；
    
4.  问题通常在联系失败后才暴露，处理滞后，增加平台协调成本。
    

---

## 3. 目标

### 3.1 业务目标

为平台联系方式字段补充通用的**有效性校验和标准化**能力，确保：

1.  用户只能提交一个有效联系方式；
    
2.  虚拟号模块拿到的是处理后的标准联系方式；
    
3.  姓名、联系时间、备注、多个号码等非纯联系方式内容在提交前被拦截。
    

### 3.2 非目标

本次不做：

*   不校验号码是否真实存在或是否实名；
    
*   不调用运营商接口验证号码状态；
    
*   不在联系方式字段中承载联系人姓名、联系时间、备注；
    
*   不支持境外电话号码。
    

---

## 4. 产品方案

### 4.1 字段处理

联系方式字段采用“**纯联系方式输入 + 标准化**”的方式处理。

| 数据 | 用途 | 处理方式 |
| --- | --- | --- |
| 用户填写的联系方式 | 页面展示、业务留痕 | 原样保存 |
| 标准联系方式 | 传给虚拟号模块 | 由用户填写的联系方式标准化生成 |

示例：

| 用户输入 | 页面展示 | 标准联系方式 |
| --- | --- | --- |
| `13800138000` | `13800138000` | `13800138000` |
| `+86 13800138000` | `+86 13800138000` | `13800138000` |
| `010-88888888` | `010-88888888` | `01088888888` |
| `400-123-4567` | `400-123-4567` | `4001234567` |

### 4.2 提交流程

1.  用户填写联系方式；
    
    ![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/AJdl65AEXQP3BOke/img/c79908ce-dc53-4f3f-9510-f2ab85de76da.png)
    
2.  系统对输入内容做轻量标准化处理；
    
3.  系统校验整段输入是否为一个有效联系方式；仅仅针对tradeStyle为竞价、反拍的时候做，仅在虚拟号开启的时候，填写完校验，不符合则提示
    
4.  如果输入包含姓名、备注、联系时间、多个号码或其他无关文本，阻止提交并提示用户；
    
5.  如果校验通过，保存用户填写的联系方式；
    
6.  将联系方式处理为标准联系方式；
    
7.  虚拟号拨打时，使用标准联系方式作为被叫号码。
    

### 4.3 虚拟号调用规则

虚拟号模块不直接使用用户填写的原始联系方式。业务调用虚拟号前，需先将联系方式处理为标准联系方式，再传给虚拟号模块。

| 原文类型 | 处理要求 |
| --- | --- |
| 手机号 | 去除 `+86`、`86`、空格、短横线等非必要字符后传入 |
| 座机号 | 去除空格、短横线等分隔符后传入 |
| 400 / 800 电话 | 去除空格、短横线等分隔符后传入 |
| 姓名、备注、联系时间 | 不允许填写 |

### 4.4 多联系方式处理

联系方式字段仅允许填写一个联系方式。如果输入中存在多个联系方式，阻止提交，不自动选择其中一个号码。

示例：

| 输入 | 处理结果 |
| --- | --- |
| `13800138000，13900139000` | 不允许提交 |
| `010-88888888，13800138000` | 不允许提交 |

如后续需要支持备用号码，应新增独立字段或明确主号码选择规则。

## 5. 校验与标准化规则

### 5.1 支持号码类型

本次支持中国大陆常见可拨打号码：

| 类型 | 支持示例 |
| --- | --- |
| 手机号 | `13800138000`、`+86 13800138000`、`86-13800138000` |
| 座机号 | `010-88888888`、`0571 88888888`、`010-88888888转123` |
| 400 / 800 电话 | `400-123-4567`、`800 123 4567` |

### 5.2 标准化处理

校验前，系统可对输入内容做以下标准化：

1.  去除首尾空格；
    
2.  全角数字转半角数字；
    
3.  中文括号转英文括号；
    
4.  长横线、中文横线统一为短横线；
    
5.  仅用于校验和生成标准联系方式，不覆盖用户原始输入。
    

### 5.3 推荐校验规则

校验规则需匹配整段输入，不允许只从文本中提取局部号码。

手机号：

```js
/^(?:\+?86[-\s]?)?1[3-9]\d{9}$/

```

座机号：

```js
/^0\d{2,3}[-\s]?\d{7,8}(?:[-\s转]\d{1,6})?$/

```

400 / 800 电话：

```js
/^(?:400|800)[-\s]?\d{3}[-\s]?\d{4}$/

```

### 5.4 标准联系方式输出格式

传给虚拟号模块前，需将用户填写的联系方式处理为标准联系方式。

| 用户输入 | 标准联系方式 |
| --- | --- |
| `+86 13800138000` | `13800138000` |
| `86-13800138000` | `13800138000` |
| `010-88888888` | `01088888888` |
| `010-88888888转123` | `01088888888` |
| `400-123-4567` | `4001234567` |

说明：

*   手机号去除 `+86`、`86` 前缀后传入；
    
*   座机号去除空格、短横线后传入；
    
*   400 / 800 电话去除空格、短横线后传入；
    
*   分机号本期不传给虚拟号模块，避免影响拨号成功率；
    
*   如果虚拟号模块后续支持分机拨打，可再扩展分机传参。

## 6. 交互要求

当联系方式不符合规则时，提示：

> 请填写有效联系电话，不要填写姓名、联系时间或备注

## 7. 验收标准

### 7.1 应允许提交

| 输入 | 标准联系方式 |
| --- | --- |
| `13800138000` | `13800138000` |
| `+86 13800138000` | `13800138000` |
| `86-13800138000` | `13800138000` |
| `010-88888888` | `01088888888` |
| `400-123-4567` | `4001234567` |
| `800 123 4567` | `8001234567` |

### 7.2 应阻止提交

| 输入 | 原因 |
| --- | --- |
| `张三 工作日联系` | 未识别到有效号码 |
| `张三 13800138000` | 包含姓名，不是纯联系方式 |
| `13800138000（工作日8点-18点）` | 包含联系时间，不是纯联系方式 |
| `13800138000，13900139000` | 包含多个联系方式 |
| `1380013800` | 手机号不足 11 位 |
| `12800138000` | 不符合手机号段规则 |
| `010-12345` | 座机主号码位数不足 |
| `12345` | 不符合手机号、座机号或服务电话规则 |

### 7.3 虚拟号验收

| 场景 | 预期 |
| --- | --- |
| 联系方式包含姓名 | 不允许提交，不调用虚拟号模块 |
| 联系方式包含备注 | 不允许提交，不调用虚拟号模块 |
| 联系方式包含短横线或空格 | 虚拟号模块收到去除分隔符后的标准联系方式 |
| 联系方式为座机号 | 虚拟号模块收到标准化后的座机号码 |
| 联系方式无有效号码 | 不允许提交，不调用虚拟号模块 |
