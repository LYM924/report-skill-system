# 竞价新增“中标价格是否公示”选择项

## 概览
竞价结果公告当前默认展示中标价格，但部分能源、资源类业务因价格敏感需保密。湖南国资云实例提出需求，要求在竞价结果确认环节增加采购人对中标价格是否公示的选择权，以实现合规披露。通过交易方式配置与结果确认页优化，系统将根据采购人选择控制公告及相关页面的价格展示，确保信息管控一致且符合业务实际。
关键要点包括：
1. 新增交易方式配置项：在竞价交易方式中增加“是否允许设置中标价格公示状态”配置，默认关闭，开启后采购人可在结果确认页自主选择是否公示中标价格。
2. 结果确认页支持选择公示状态：配置开启时，结果确认页新增“公示中标价格”选项，默认选中“公示”，采购人可切换为“不公示”，最终以发布时选择为准。
3. 多入口统一价格展示控制：当选择“不公示”时，公告大厅、公告详情页及非中标供应商查看页面均不展示中标价格，字段可隐藏或显示为“-”。
4. 保留内部价格数据完整性：无论是否对外公示，系统内部仍保留真实中标价格，用于履约、结算及内部查询，确保业务连续性与数据安全。
---

## 1. 背景

竞价结果公告当前会展示中标价格。部分竞价业务涉及能源、资源、企业经营等敏感价格信息，中标价格具有一定行业保密性，不适合在公告大厅、公告详情等公开页面直接披露。

本次需求来源于湖南国资云实例。湖南国智云科技有限公司为湖南国资云平台合作方，其所属省属国企湖南能源集团存在能源类竞价业务，中选价格具有行业保密性，需要在发布竞价结果公告时支持由采购人选择是否公示中标价格。

## 2. 当前问题

当前竞价结果公告中标价格公示能力存在以下不足：

1.  竞价结果公告默认展示中标价格，采购人无法按业务需要选择隐藏；
    
2.  价格敏感类竞价业务无法通过系统公告完成合规发布，只能依赖线下沟通或特殊处理；
    
3.  公告大厅、公告详情、供应商查看结果等多个入口均可能暴露中标价格，信息披露口径不统一时存在业务风险。
    

---

## 3. 目标

### 3.1 业务目标

在竞价结果确认环节，支持采购人选择“中标价格是否公示”，并按最终选择结果控制竞价结果公告及相关查看入口中的中标价格展示。

---

## 4. 产品方案

### 4.1 交易方式配置：是否允许设置中标价格公示状态

在竞价交易方式配置中新增配置项，用于控制采购人是否可在结果确认页选择中标价格公示状态。

| 字段 | 说明 |
| --- | --- |
| 配置名称 | 是否允许设置中标价格公示状态 |
| 默认值 | 不允许 |
| 生效范围 | 仅影响竞价、反拍交易方式 |
| 配置关闭时 | 结果确认页不展示“中标价格是否公示”选择项，公告按现有规则展示中标价格 |
| 配置开启时 | 结果确认页展示“中标价格是否公示”选择项 |

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/1wvqreb9bEgd3nak/img/2b28ae86-d2ad-47a6-84d0-c48748983f99.png)

### 4.2 结果确认页：中标价格是否公示

当交易方式配置开启后，在竞价结果确认页新增“公示中标价格”选择项。

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/1wvqreb9bEgd3nak/img/d23d4c9e-32ee-4992-8134-29afb0d421df.png)

| 字段 | 说明 |
| --- | --- |
| 字段名称 | 公示中标价格 |
| 默认值 | 公示 |

交互规则：

1.  默认选中“公示”，避免采购人误操作导致应公开价格未公开；
    
2.  采购人可在结果确认前切换为“不公示”；
    
3.  反复切换时，以最终确认发布时的选择为准；
    
4.  已发布公告不支持通过该选择项自动回刷，如需变更按现有公告更正流程处理。
    

### 4.3 公告及页面展示

当采购人选择“公示”时，各页面按现有规则展示中标价格。

当采购人选择“不公示”时，以下入口不展示中标价格：

| 入口 | 展示规则 | 页面 |
| --- | --- | --- |
| 公告大厅 | 不展示中标价格字段或价格值 | 竞价升级公告大厅、湖南 XXX 大厅、竞价变更公告 |
| 竞价结果公告详情 | 不展示中标价格字段或价格值 | 元数据不传 |
| 非中标供应商查看结果详情 | 中标价格展示为 `-` |  |

说明：

1.  若页面已有中标价格字段且不便隐藏整列，可展示为 `-`；
    
2.  若公告模板中存在中标价格书签或变量，选择“不公示”时不输出价格值；
    
3.  系统内部仍需保留真实中标价格，用于交易记录、履约、结算或后续内部查询。
