# 逾期供应商未结清账单不允许参与竞价报价

## 概览
为加强重庆乐采商城国企业务中交易服务费回款管理，平台拟在竞价与反拍交易方式中新增“限制欠款供应商报价”配置。通过在报价环节前置校验供应商是否存在逾期未结清账单，实现对欠费供应商参与新交易的拦截，推动历史账单结清，保障线上交易闭环与服务费回收。
关键要点包括：
1. 问题定位：现有拦截机制滞后当前“逾期商家不能接单”控制仅作用于订单环节，无法阻止欠费供应商在竞价、反拍中报价并中选，存在引导线下交易导致服务费流失的风险。
2. 核心目标：前置报价拦截能力在供应商参与竞价或反拍的报价阶段增加欠款校验，若存在逾期未结清交易服务费，则禁止其提交或修改报价，防止风险前移。
3. 可配置化规则支持灵活启用新增“限制欠款供应商报价”交易规则配置项，默认关闭，支持按交易方式或实例开启，满足不同业务场景对欠款供应商管控的差异化需求。
4. 全流程报价节点校验机制配置开启后，在创建、提交、修改及重新报价等关键节点均进行欠款状态校验，并通过弹窗提示引导供应商完成支付。
5. 明确用户引导与操作路径拦截时展示标准化弹窗，提供“去支付”跳转链接直达应付账单列表，确保供应商可快速完成缴费并恢复报价资格。
---

## 1. 背景

重庆乐采商城国企业务中，竞价、反拍等交易方式允许供应商先参与报价，采购人确认结果后再进入后续订单或履约流程。

当前平台已有“逾期商家不能接单”相关控制，但该控制主要作用于接单或订单环节，无法覆盖供应商在竞价、反拍过程中的报价行为。部分存在历史待缴交易服务费账单的供应商，仍可能先参与报价并中选，再引导采购人线下完成后续流程，影响平台交易服务费回款和线上交易闭环。

为降低逾期欠费供应商继续参与新交易的风险，需要在竞价、反拍报价环节增加欠款拦截能力。

## 2. 当前问题

1.  逾期供应商未结清历史待缴交易服务费账单时，仍可能参与新的竞价或反拍报价；
    
2.  现有“逾期商家不能接单”逻辑无法完全覆盖报价阶段，拦截时点偏后；
    
3.  供应商中选后若引导采购人转线下交易，平台难以及时推动历史账单结清；
    
4.  不同交易方式、不同实例对欠款供应商是否限制报价的要求可能不同，缺少可配置控制。
    

---

## 3. 目标

在竞价、反拍交易方式中新增“限制欠款供应商报价”配置。配置开启后，正式供应商如存在逾期未结清的历史交易服务费账单，不允许参与新的报价或修改报价，并引导供应商前往应付账单列表完成支付。

---

## 4. 产品方案

### 4.1 新增交易规则配置

在交易方式或实例规则配置中新增配置项：限制欠款供应商报价。

| 配置项 | 说明 |
| --- | --- |
| 配置名称 | 限制欠款供应商报价 |
| 默认值 | 关闭 |
| 适用交易方式 | 竞价、反拍 |
| 配置关闭时 | 不校验供应商逾期待缴账单，按现有报价流程执行 |
| 配置开启时 | 供应商报价或修改报价时，校验是否存在逾期未结清交易服务费账单 |

说明：配置默认关闭，避免影响存量实例和存量交易方式；如实例或区划有交易服务费回款诉求，可按需开启。

### 4.2 报价环节欠款校验

配置开启后，供应商进入报价流程时，系统需查询该供应商是否存在逾期未结清的交易服务费账单。

| 校验节点 | 处理规则 |
| --- | --- |
| 创建报价单 | 如存在逾期未结清账单，展示拦截提示，不允许继续报价 |
| 提交报价 | 提交前再次校验；如存在逾期未结清账单，阻止提交 |
| 修改报价 | 按提交报价同样规则校验；存在逾期未结清账单时不允许修改 |
| ~~重新报价~~（不校验） | ~~供应商支付成功且报价未截止时，可重新进入报价流程~~ |

### 4.3 拦截弹窗

当供应商存在逾期未结清交易服务费账单时，报价页展示提示弹窗。
