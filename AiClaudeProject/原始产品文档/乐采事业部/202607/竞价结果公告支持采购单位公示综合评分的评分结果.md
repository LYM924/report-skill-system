# 竞价结果公告支持采购单位公示综合评分的评分结果

## 概览
为提升竞价采购综合评分结果的透明度，文章提出在结果公告中增加供应商评分详情的公示功能。通过配置开关控制是否开放该功能，并在结果确认环节由采购单位自主选择是否公示，确保信息同步、提升公信力与审计合规性。
关键要点包括：
1. 新增配置项：在竞价交易方式中增加“是否允许公示评分详情”配置，默认关闭，仅在推荐规则为“综合评分”或“采购人自行选择”时可见。
2. 结果确认页交互优化：当配置开启时，在结果确认环节提供【公示评分结果】按钮，供采购单位自主决定是否将评分详情随公告发布。
3. 公告内容结构化展示：公示时新增“竞价综合评分结果”书签，列出各供应商名称、总分及各项大项得分，不展示子项分数，供应商按得分降序排列。
4. 影响范围明确：功能仅影响综合评分类竞价单，涉及配置页、结果确认页和公告模板；历史公告不受影响，不进行数据回刷。
5. 验收标准清晰：从配置展示、按钮行为到公告内容均设定具体验收场景，确保功能按预期稳定运行，且数据准确一致。
---

## 1. 背景

竞价采购使用综合评分方式时，当前结果公告中仅展示评分规则（各项评分大项及权重），不展示各供应商的具体得分。部分采购单位在完成评审后，需要将供应商的评分结果一并向社会公示，以满足公开透明的监管要求或内部审计需要。

## 2. 当前问题

竞价综合评分的结果公告存在以下不足：

1.  仅公示评分规则，缺少各供应商实际得分信息；
    
2.  采购单位如需要公示评分结果，只能通过线下方式（如张贴公告、另行发文），效率低且存在公示不同步的风险；
    
3.  供应商无法从公告中获知自身与竞争对手的得分差距，公示信息不够充分。
    

---

## 3. 目标

### 3.1 业务目标

在竞价综合评分的结果确认环节，支持采购单位选择是否公示供应商评分结果，公示后评分详情随竞价结果公告一同发布。

---

## 4. 产品方案

### 4.1 配置项：是否允许公示评分详情

在竞价交易方式的配置中新增"是否允许公示评分详情"配置项。

| **字段** | **说明** |
| --- | --- |
| 配置名称 | 是否允许公示评分详情 |
| 默认值 | 不允许 |
| 展示条件 | 当推荐规则类型为"综合评分"或"采购人自行选择"时展示该配置 |
| 生效范围 | 仅影响竞价交易方式 |

### 4.2 页面交互：公示评分结果按钮

在综合评分竞价单的结果确认环节，增加【公示评分结果】按钮。

| 场景 | 行为 |
| --- | --- |
| 配置关闭时 | 按钮不展示，公告不包含评分结果 |
| 配置开启 + 用户选择公示 | 公告中展示供应商评分结果 |
| 配置开启 + 用户不公示 | 公告中不展示评分结果（默认） |

按钮位置示意：

### 4.3 公告展示

#### 4.3.1 公告结构

竞价结果公告新增书签"竞价综合评分结果"，由业务自行配置展示。

#### 4.3.2 展示字段

| 字段 | 说明 |
| --- | --- |
| 供应商名称 | 参与竞价的供应商名称 |
| 综合评分 | 供应商综合评分总分 |
| 评分详情 | 各评分大项的得分（子项分数不展示） |

公告展示示意：

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/NpQlK5jBYwGJNqDv/img/5a494ca9-8ec0-44e1-aacd-57db23dd104b.png)

#### 4.3.3 展示规则

1.  评分详情按评分大项逐一列示，仅展示大项得分；
    
2.  子项分数不展示；
    
3.  供应商按评分降序排列。

## 5. 影响范围

| 场景 | 说明 |
| --- | --- |
| 竞价配置页 | 新增"是否允许公示评分详情"配置项 |
| 结果确认页 | 新增"公示评分结果"按钮 |
| 竞价结果公告 | 新增"竞价综合评分结果"书签及对应内容 |
| 公告预览 | 预览时展示评分结果（如已选择公示） |
| 公告模板 | 评分结果数据需写入公告模板对应位置 |

以下场景不受影响：

*   非综合评分的竞价单不展示相关配置和按钮；
    
*   已发布的历史公告不回刷评分结果；
    
*   监管端、供应商端查看评分明细的能力不变。
    

---

## 6. 验收标准

### 6.1 配置验收

| 场景 | 预期结果 |
| --- | --- |
| 推荐规则为"综合评分" | 展示"是否允许公示评分详情"配置 |
| 推荐规则为"采购人自行选择" | 展示"是否允许公示评分详情"配置 |
| 推荐规则为其他类型 | 不展示该配置 |
| 配置默认值 | 不允许 |
| 配置改为"允许" | 结果确认页展示"公示评分结果"按钮 |

### 6.2 页面交互验收

| 场景 | 预期结果 |
| --- | --- |
| 配置为"不允许" | 结果确认页不展示按钮，公告不包含评分结果 |
| 配置为"允许"但未点击公示 | 公告不包含评分结果 |
| 配置为"允许"且点击公示 | 公告包含评分结果 |
| 反复切换公示/不公示 | 以最终确认状态为准 |

### 6.3 公告内容验收

| 校验项 | 预期结果 |
| --- | --- |
| 公告是否包含"竞价综合评分结果"书签 | 选择公示时包含，未公示时不包含 |
| 供应商名称 | 与参与竞价的供应商一致 |
| 综合评分总分 | 与系统评分结果一致 |
| 评分详情大项分数 | 与系统评分大项得分一致 |
| 子项分数 | 不展示 |
| 历史公告 | 不受影响，不回刷 |
