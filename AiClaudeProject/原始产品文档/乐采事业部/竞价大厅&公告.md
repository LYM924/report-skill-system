# 竞价大厅&公告

# 1. 产品概述

大厅和公告是竞价信息的重要触达点，在竞价发布、变更、完成和终止等环节，承担着向外发布信息的重要作用。一方面，应该尽可能全面、准确、清晰地进行信息传递；另一方面，也需要向采购人和供应商传递平台价值，加强平台竞争力。

# 2. 市场分析与用户需求

## 2.1 需求背景

目前竞价大厅混杂着邀请公告和结果公告，查看商机需要多层跳转，商机暴露不足；

## 2.2 用户需求分析

### 用户画像

**供应商**：供应商大A，是一个做公仔定制的厂家，他的工厂设置在浦江县，在当地客情关系良好。

### 需求场景

1.  大 A 与 蒲阳县幼儿园的客情较好，每次幼儿园有采购需求时，会跟大 A 打个招呼，大 A 到政府采购网上，找到这家幼儿园的竞价单，进行报价。 
    
2.  随着当地业务的深入，大 A 想拓展一些周边的业务，例如金华市、杭州市、丽水市等。温州、台州等地，距离较远，运输成本高，目前还没有拓展计划。  
    
3.  为了即时跟进最新的商家，大 A 每天都会花时间看一看新发布的竞价单。
    
4.  为了更容易中标，大 A 也会去看一下其他厂商的成交公告，了解竞争对手，优化后续的产品和报价策略。
    
    # 产品设计
    
    ### 竞价大厅
    
    #### 增加竞价大厅落地页，承担重点功能导航和平台价值露出。
    
    1.  重点功能：商机大厅、公告入口
        
    2.  平台价值：
        
        1.  交易量大：累计交易额、
            
        2.  交易活跃：今日发布、最新成交
            
        3.  交易金额大：大额采购数量
            
        4.  成交率高：周边项目
            
    
    #### 优化商机大厅
    
    1.  承担纯粹的商机展示任务。
        
    2.  供应商查看有哪些合适自己的商机（区域、行业）
        
    3.  熟客交易（快速查找熟客发布的线索）
