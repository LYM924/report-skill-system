# 乐采竞选2.0

# 产品简介

平台建立的一套**商品优选与标识**机制，旨在为**​采购人​**​筛选出具备​**​低价优势​**​和​**​标品属性​**​的优质商品集合，并提供有力的**采购依据**。

这些商品经过平台严格的比价和筛选流程，被标记为“精品”，享有平台提供的信任背书（**比价证明**）及相应的采购便利性（搜索加权、专区等）支持。

# 产品价值

平台优选，预先比价，放心直购

# 运营管理页面

*   商品名称、类目支持筛选；价格信息支持排序；
    
*   商品名称可点击跳转到商品详情页。
    
*   实例规则可设置：
    
    *   实例共享规则（可共享到其他实例）
        
    *   商品筛选规则
        
        *   电商平台平均价
            
        *   平台平均售价、成交价
            
        *   推送周期等
            
*   数据更新规则
    
    *   重复数据只更新销量、价格等信息；
        
    *   销量、价格、平台平均成交价、平台平均售价实时读取商品中心的数据。
