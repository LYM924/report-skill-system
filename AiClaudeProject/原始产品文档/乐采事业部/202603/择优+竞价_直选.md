# 择优+直选

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/v9kqDejakPwMaOVx/img/b397e6f0-5030-40d0-b78e-65bb5e37d00f.png)

*   择优时，不可见报价信息
    
*   必须选择有效家数以上的供应商进入直选环节
    
*   择优结果提交后，不可回退
    

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/v9kqDejakPwMaOVx/img/4f3b87c7-e9e8-4ed6-83ff-7eb013e052e8.png)

*   直选：采购人可在择优后的供应商中选择供应商。
    

# 择优 + 竞价

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/v9kqDejakPwMaOVx/img/c1817104-2acc-4937-9f14-f34c18df880f.png)

*   择优时，不可见报价信息
    
*   择优结果提交后，不可回退
    
*   必须选择有效家数以上的供应商进入直选环节
    
*   若有结果变更，回退至择优流程
    

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/v9kqDejakPwMaOVx/img/01178a22-3e1e-41b6-b8fa-0c8b956a0e62.png)

*   竞价：采购人不可选择供应商，自动推荐报价最低的供应商
