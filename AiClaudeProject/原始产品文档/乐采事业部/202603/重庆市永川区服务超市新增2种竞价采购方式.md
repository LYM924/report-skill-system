# 重庆市永川区服务超市新增2种竞价采购方式
## 作者：蔚然、新瑶
## 概览
永川区服务超市为提升采购量，拟在现有采购方式基础上新增“择优+竞价”和“择优+直选”两种模式，通过前置择优筛选供应商且屏蔽报价信息，确保公平性与专业性，最终实现平台交易额增长。
关键要点包括：
1. 新增两种采购模式：在原有直购、竞价、反拍基础上，增加“择优+直选”和“择优+竞价”，支持采购人先基于非价格因素筛选供应商。
2. 择优阶段报价不可见：采购人在择优时无法查看供应商报价，防止价格干扰，确保筛选基于服务能力等综合因素。
3. 最低选择家数限制：择优时必须选择不少于“有效家数”的供应商，前端置灰提交按钮并配合后端双校验，确保合规。
4. 流程不可回退机制：择优结果提交后不可主动回退，仅在竞价阶段发生异常（如最低价弃标）时系统自动回退至择优阶段。
5. 结果自动生成与展示：“择优+竞价”由系统自动推荐最低报价供应商，“择优+直选”由采购人手动选定，界面明确标识择优结果及推荐状态。

## 1. 功能概述

本功能在常规竞价流程基础上，增加**择优**前置环节：采购人在不可见报价的情况下，从所有响应供应商中筛选出合格供应商，再进入后续的竞价或直选阶段。

支持两种子模式：

| 模式 | 说明 |
| --- | --- |
| **择优 + 直选** | 择优后，由采购人从通过择优的供应商中手动选定中标供应商 |
| **择优 + 竞价** | 择优后，系统自动推荐报价最低的供应商为中标候选，采购人不可手动干预 |

## 5. 择优 + 直选 流程

### 5.1 流程

1.  供应商报价完成，进入**择优阶段**。
    
2.  采购人对响应供应商进行择优操作（**报价信息不可见**）。
    
3.  采购人选择不少于「有效家数」的供应商，提交择优结果。| 注意提示文案
    
4.  提交后**不可回退**，进入**直选阶段**。
    
5.  采购人在择优后的供应商中选定最终供应商，完成直选。

### 5.3 业务规则

| **规则** | **说明** |
| --- | --- |
| 择优阶段报价不可见 | 采购人在择优操作时，不可查看供应商报价金额，防止依据价格主观筛选；由现有配置控制 |
| 最低选择家数限制 | 择优时，选择供应商数量必须 >= 有效家数，否则不允许提交。**前端 + 后端双校验** |
| 择优结果不可回退 | 提交后状态流转为「直选阶段」，不提供撤销或回退操作入口 |
| 直选阶段可见报价 | 进入直选阶段后，采购人可查看择优后供应商的报价信息，辅助最终决策 |
| 直选范围限制 | 采购人只能从**择优已选供应商**中进行直选，不能选择择优阶段被淘汰的供应商 |

## 6. 择优 + 竞价 流程

### 6.1 流程

1.  供应商报价完成，进入**择优阶段**。
    
2.  采购人对响应供应商进行择优操作（**报价信息不可见**）。
    
3.  采购人选择不少于「有效家数」的供应商，提交择优结果。
    
4.  提交后**不可主动回退**，进入**竞价阶段**。
    
5.  系统自动从择优结果中推荐**报价最低**的供应商为中标候选，**采购人不可手动干预**。
    
6.  若发生结果变更（如最低价供应商弃标等），系统自动**回退至择优阶段**，由采购人重新操作。
    

### 前端交互要求

| **交互点** | **要求** |
| --- | --- |
| 择优选择供应商 | 勾选框操作；选中数量实时显示，低于有效家数时提交按钮**置灰**并提示 |
| 提交择优前确认弹窗 | 提交前弹出二次确认："提交后不可回退，是否确认？" |

### 6.3 业务规则

| 规则 | 说明 |
| --- | --- |
| 择优阶段报价不可见 | 同择优+直选，择优时不可查看报价金额；由现有配置控制 |
| 最低选择家数限制 | 选择供应商数量必须 >= 有效家数，**前端 + 后端双校验** |
| 择优结果不可回退 | 提交后进入竞价阶段，不可主动回退；仅在结果变更时由系统触发回退 |

| 结果变更回退逻辑 | 若当前最低价供应商发生变更，系统将状态回退至「待择优」，通知采购人重新择优 |
