## 作者：蔚然
# 一、抽取规则

##  分组规则（按“最近抽取时间”划分）

所有报名供应商，按最近一次抽取时间分为5组：

*   A组（优先组）：👉 30天及以上未中标（或从未中标）
    
*   B组：👉 20～30天未中标
    
*   C组：👉 10～20天未中标
    
*   D组：👉 5～10天未中标
    
*   E组（最低优先级）：👉 5天内中标过
    

## 抽取顺序（核心规则）

系统按以下顺序逐级判断：

*   优先从 A组 中随机抽取
    
*   若A组无人 → 从 B组 抽取
    
*   若B组无人 → 从 C组 抽取
    
*   若C组无人 → 从 D组 抽取
    
*   若D组无人 → 从 E组 抽取
    

## 抽取方式

在选定的组内：👉 完全随机抽取1家供应商

# 二、举例说明

假设某项目报名情况：

A组：3家 B组：4家 C组：2家 D组：3家 E组：1家

👉 本次抽取：

直接在 A组3家中随机选1家；其他组不参与

### 再看一个边界情况：

A组：0 B组：0 C组：5家

👉 本次抽取：

从 C组5家中随机选1家
