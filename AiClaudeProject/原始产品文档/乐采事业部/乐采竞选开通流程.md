# 乐采竞选开通流程

# 发送邮件开通相关实例

目前乐采竞选在产品设计上限制较多，为防止意外，产研额外增加了一层开关。

*   邮件发送：天涯、流沙、修齐、蔚然、自身主管
    
*   邮件内容说明开启实例及其 code，开启时间。
    

# 交易业务规则中开启寻源竞价

该配置必须切换到【**机构级**】，否则区划/实例下所有的采购单位都将有发起乐采竞选的能力。

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/XNkOMMyGma0gOY74/img/9bbfc771-7999-4531-bf71-05f76c0712aa.png)

# 开启后台发起入口

确保【后台列表页】选中。

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/XNkOMMyGma0gOY74/img/9ccfb6cb-51c7-4ae8-a6bd-2be4aba3b770.png)

# 发起

选择正确的业务类型和交易方式发起。

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/XNkOMMyGma0gOY74/img/3eec4898-109a-4b45-a49e-23abb1acf18b.png)

查看是否正确：基本信息中展示了【期数】即为正确打开了乐采竞选。若上述三步操作均以完成，【期数】未显示，请联系开发人员排查。
