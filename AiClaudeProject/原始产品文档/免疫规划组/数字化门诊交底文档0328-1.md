# 数字化门诊交底文档0328-1

# 一、背景说明

1、免疫规划一体化系统切换后，已经在使用的数字化门诊也需要进行同步切换，否则将无法正常开展业务，或智能通过手写板等基础工具来进行业务操作。需进行兼容。

2、后续的新数字化门诊实施时，可以此文档为参考。

3、两种不同的场景

3-1、已开展数字化门诊，已有机器，需在此次实施过程中进行兜底。

3-1-1、不同情况的处理方式

*   取号机是windows系统，屏幕系统是安卓4.4版本及以上的，支持改造；。
    
*   取号机是安卓系统，屏幕系统是安卓4.2版本或者无法显示安卓桌面的，不支持改造。
    
*   签核机是惠能、银信、哲勤等厂商特定型号的。可进行改造；其他类型的，暂时不支持改造
    

3-2、未开展数字化门诊，有数字化门诊需求

3-2-1、如单位需采购相关设备，可联系 $\color{#0089FF}{@申磊 (利奥)}$ 

4、常见的问题说明

| 问题 | 回复 |
| --- | --- |
| 叫号的LED是否会支持？ | Led屏因市场上已经采买不到相应的控制卡，故不做优化和兜底 |
| 新系统上线后，只能用大将军吗，还是可以用原来的手写板？ | 是支持的，只是作为写入设备，类似扫码枪的作用，但是需要有配套的驱动程序。 |

# 二、文档目的

1、帮助产品、研发、实施、市场、运营、客满同学，熟悉数字化门诊的相关功能模块及操作流程。

2、为数字化门诊整体顺利切换提供基础
