# 收费平台支付失败

## 问题描述

收费平台支付时提示失败？

## 原因分析

1. 支付通道异常
2. 账户余额不足
3. 支付限额超限

## 解决方法

1. 检查支付通道是否正常（微信/支付宝/银行）
2. 确认账户余额充足
3. 检查是否超过单笔/单日支付限额
4. 如仍失败，联系收费平台管理员

## 排查要点

- [ ] 支付通道是否正常
- [ ] 账户余额是否充足
- [ ] 是否超过支付限额
