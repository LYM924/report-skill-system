# 电子档案归档后无法检索

## 问题描述

电子档案归档后在系统中检索不到？

## 原因分析

1. 归档索引未及时更新
2. 检索关键词不匹配
3. 档案权限限制

## 解决方法

1. 等待索引更新（通常5分钟内完成）
2. 尝试用档案编号或文件名检索
3. 检查档案权限设置，确认有查看权限

## 排查要点

- [ ] 索引是否已更新
- [ ] 检索关键词是否准确
- [ ] 是否有档案查看权限
