# 接种记录无法保存

## 问题描述

预防接种记录提交后保存失败？

## 原因分析

1. 接种人信息不完整
2. 疫苗批号错误
3. 接种日期不在有效期内

## 解决方法

1. 检查接种人信息是否完整（姓名、身份证号等）
2. 核对疫苗批号是否正确
3. 确认接种日期在疫苗有效期内
4. 如仍失败，检查网络连接后重试

## 排查要点

- [ ] 接种人信息是否完整
- [ ] 疫苗批号是否正确
- [ ] 接种日期是否在有效期内
