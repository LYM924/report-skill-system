# 合同审批流程如何配置

## 问题描述

合同审批流程在哪里配置？

## 原因分析

合同审批流程需要在运营后台配置，支持按金额和类型设置不同审批层级

## 解决方法

1. 登录运营后台
2. 进入流程管理→合同审批流程
3. 按合同金额、类型设置不同审批层级
4. 保存后生效

## 排查要点

- [ ] 是否有运营后台权限
- [ ] 合同金额层级是否正确
- [ ] 审批人是否已配置
