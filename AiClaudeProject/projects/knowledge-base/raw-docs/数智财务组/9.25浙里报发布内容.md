# 9.25浙里报发布内容

# 【惠企利民】支持财务侧和业务侧发起报销

使用单位：余省心（余杭财政）

背景：余省心仅使用新菜单“惠企利民”发起报销，财务老师使用该菜单时存在未审核的数据，因此建议需要业务方发起审批后再由财务审批才支付，本期增加双通道使用余省心推送的兑付请求进行完成支付

功能说明：

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/QvjnA3jA6PWPbOXo/img/d2ee52d4-4f08-4b9b-bb08-6bdb94529dfd.png)

### 1、场景配置

①企业兑付的场景迁移至批量发放，页面不显示“企业兑付”的场景配置，注意数据迁移和原“企业兑付”场景ID的调整

*   运营机构->实施工具->单位管理→业务规则→场景配置
    
*   运营机构->实施工具->租户管理→业务规则→场景配置
    

②批量发放的场景，分成如下几块设置，第一块是使用范围配置，增加提示说明；第二块区分业务侧发放配置和财务侧发放配置，都有提示说明

*   运营机构->实施工具->租户管理→业务规则→场景配置：仅在租户侧有，余省心是租户侧的，因此配置在租户维度
    

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/QvjnA3jA6PWPbOXo/img/4287ff9c-8ba6-441a-8e22-c6eee69e9bf3.png)

*   业务侧发放配置：针对余省心，需要开启从“兑付申报单”取值，则不再支持手动导入收款账户；同时数据范围勾选“业务处理”
    
*   财务侧发放配置：针对余省心，需要开启从“兑付申报单”取值，同时数据范围勾选“财务处理”
    

\------实现效果，业务侧发起的报销仅支持选择余省心没有审批流的数据，财务侧发起的报销仅支持选择余省心有审批流的数据

### 2、财务侧发起兑付报销

财务操作入口：惠企利民->兑付发放单->【创建发放申请】

\>>操作流程保持不变，第二步“选择申报单”时，仅支持选择到有审批信息的申报单，具体审批流程可点击“详情”查看\`\`\`\`\`\`\`\`\`\`\`\`\`

### 3、业务侧发起兑付报销

业务员操作入口：支出管理->我的单据->【创建报销单】批量报销

\>>业务人员在批量报销流程不变，在第二步选择批量发放明细（选择账户）时，仅允许【选择申报单】【批量删除】，交互同财务人员，业务人员可选择没有审批流的申报单，可通过详情查看审批情况

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/QvjnA3jA6PWPbOXo/img/e5a255dc-94b8-4e4a-a0c5-698e4b092e8a.png)
