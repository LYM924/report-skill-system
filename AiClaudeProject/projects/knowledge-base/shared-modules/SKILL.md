# 产品知识库

## 检索策略

当用户提问或搜索时，按以下优先级匹配：

```
用户提问/搜索
  ├── 0. 关键词库检索（优先） → 关键词库/关键词索引.md
  │     └── 命中 → 得到产品模块+所属部门+业务域 → 定位 Skill 文件或知识库
  ├── 1. 匹配业务域目录（浙里报/孵化业务/徽报账/直属/电子档案/免疫规划/数字化支撑）
  │     └── 命中 → 进入对应目录，按模块名+关键词匹配具体文件
  ├── 2. 匹配一级菜单名（支出管理/财务管理/预算管理/...）
  │     └── 命中 → 通过菜单映射表找到对应产品模块 → 进入对应文件
  ├── 3. 匹配二级/三级菜单名（我的票据/发票管理/出纳结算/...）
  │     └── 命中 → 直接定位到对应模块文件
  └── 4. 直接匹配关键词
        └── 命中 → 直接定位到对应模块文件
```

## 使用说明

### 工单归类

1. 根据工单中的"模块"字段，在模块索引中找到对应模块文件
2. 从模块文件的 frontmatter 中获取：产品、产品线、二级部门、附录、负责人
3. 按附录归类到周报对应章节

### 模块负责人查找

从上方的模块索引表查找，或进入对应模块文件查看 `## 关联信息` 章节。

### 菜单→模块查找

1. 根据菜单名称，在一级菜单↔产品模块表中找到对应行
2. 进入对应模块文件查看详细的二级/三级菜单映射
3. 也可直接使用 Python MENU_TO_MODULE dict 速查

## 双向链接体系

> 四层知识体系（关键词库↔模块文件↔知识库↔报表）已打通双向链接。

### 体系架构

```
关键词库/关键词索引.md  ←→  模块文件({部门}/{业务域}/{模块}.md)
       ↕                          ↕
  知识库(knowledge/)  ←→  报表(report-system/output/)
```

### 中央枢纽

**[双向链接枢纽.md](双向链接枢纽.md)** — 四层体系的总导航站，包含：
- 完整模块→链接映射表（71个模块的四层链接）
- 三种典型使用场景（工单归类/报表分析/知识库更新）
- 维护规则

### 各层链接规范

**模块文件**（每个 `{模块}.md`）底部有 `## 双向链接` 章节，包含：
- 关键词索引链接
- 知识库链接
- 报表链接
- 中央枢纽链接

**知识库文件**（每个版本迭代文档）顶部有 `## 双向链接` 表格，包含：
- 关键词索引链接
- 模块文件链接
- 报表链接
- 中央枢纽链接

**报表文件**（每份周报）末尾有 `## 关联资源` 章节，包含：
- 知识库链接
- 模块文件链接
- 关键词索引链接
- 中央枢纽链接

**关键词索引**（关键词索引.md）包含：
- 每行的"模块文件"列（关键词→模块文件直接跳转）
- 反向索引章节（报表→关键词/模块反向追溯）
- 知识库→模块映射

### 使用示例

```
工单归类流程：
  工单描述 → 关键词索引 → 模块文件(负责人/附录) → 知识库(版本历史) → 报表(历史工单)

报表分析流程：
  周报问题 → 反向索引(涉及模块) → 模块文件(负责人) → 知识库(版本修复) → 关键词索引(扩展关键词)
```
