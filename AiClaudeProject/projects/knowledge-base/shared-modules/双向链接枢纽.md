# 双向链接枢纽

> 四层知识体系的中央导航站。从任意一层出发，均可通过本枢纽跳转到其他三层。

## 体系总览

```
┌──────────────────────────────────────────────────────────────┐
│                    双向链接枢纽 (本文件)                       │
│                                                              │
│   ┌──────────┐    ┌──────────┐    ┌──────────┐    ┌────────┐ │
│   │ 关键词库  │◄──►│ 模块文件  │◄──►│ 知识库    │◄──►│ 报表    │ │
│   │          │    │          │    │          │    │        │ │
│   │ 关键词   │    │ 模块.md  │    │ 版本迭代  │    │ 周报   │ │
│   │ 索引.md  │    │ 菜单映射  │    │ 功能说明  │    │ 月报   │ │
│   └────┬─────┘    └────┬─────┘    └────┬─────┘    └───┬────┘ │
│        │               │               │              │       │
│        └───────────────┴───────────────┴──────────────┘       │
│                        双向链接                                │
└──────────────────────────────────────────────────────────────┘
```

## 四层入口

### 1. 关键词库 → 其他三层

| 入口 | 路径 | 可跳转到 |
|------|------|---------|
| [关键词索引](关键词库/关键词索引.md) | 关键词库/关键词索引.md | 模块文件(模块文件列)、知识库(知识库路径列)、报表(反向索引) |
| [关键词库 SKILL](关键词库/SKILL.md) | 关键词库/SKILL.md | 检索策略、问答模板 |

**从关键词出发的典型路径：**
```
用户输入关键词 "预算"
  → 关键词索引.md → 产品模块: 预算中心
  → 模块文件: 数智财务组/浙里报/预算中心.md (负责人、菜单映射)
  → 知识库: 2026产品业务知识库/数智财务组/浙里报/ (版本迭代)
  → 报表: 反向索引 → 涉及"预算"的周报列表
```

### 2. 模块文件 → 其他三层

| 入口 | 路径 | 可跳转到 |
|------|------|---------|
| [共享模块中心 SKILL](SKILL.md) | SKILL.md | 全部模块索引、菜单映射、组织架构 |
| 各模块文件 | {部门}/{业务域}/{模块}.md | 关键词索引、知识库、报表(通过双向链接章节) |

**从模块文件出发的典型路径：**
```
打开 预算中心.md
  → 关键词索引: 关键词库/关键词索引.md (查看所有相关关键词)
  → 知识库: 2026产品业务知识库/数智财务组/浙里报/ (查看版本迭代)
  → 报表: 2026报表数据知识库/周报/ (查看涉及预算中心的周报)
```

### 3. 知识库 → 其他三层

| 入口 | 路径 | 可跳转到 |
|------|------|---------|
| [产品知识库 SKILL](../产品知识库/SKILL.md) | ../产品知识库/SKILL.md | 知识库架构、模板规范 |
| 各知识库文件 | 2026产品业务知识库/{部门}/{业务域}/ | 模块文件、关键词索引、报表 |

**从知识库出发的典型路径：**
```
打开 2026产品业务知识库/数智财务组/浙里报/2026-05_版本迭代.md
  → 模块文件: 共享模块中心/数智财务组/浙里报/ (查看各模块详情)
  → 关键词索引: 关键词库/关键词索引.md (查看关键词映射)
  → 报表: 2026报表数据知识库/周报/ (查看相关周报)
```

### 4. 报表 → 其他三层

| 入口 | 路径 | 可跳转到 |
|------|------|---------|
| [报表管理系统](../../报表管理系统/) | ../../报表管理系统/ | 周报/月报 SKILL |
| 各周报文件 | 2026报表数据知识库/周报/ | 模块文件、知识库、关键词索引 |

**从报表出发的典型路径：**
```
打开 2026-W26-技术支持周报.md
  → 关键词索引: 反向索引章节 → 涉及模块和关键词
  → 模块文件: 共享模块中心/{部门}/{业务域}/{模块}.md
  → 知识库: 2026产品业务知识库/{部门}/{业务域}/
```

## 使用场景

### 场景1：工单归类 → 定位模块 → 查看知识库 → 查历史报表

```
工单描述: "用户反馈预算指标同步失败"
  → 关键词索引: 搜索"指标同步" → 财政指标管理模块
  → 模块文件: 财政指标管理.md (负责人: 向前/小信，附录1)
```

## 维护规则

1. **新增模块时**：在本枢纽添加对应行，同时更新关键词索引和模块文件
2. **新增知识库文档时**：在本枢纽的"知识库→模块映射"中添加记录
3. **新增报表时**：在关键词索引的"反向索引"中添加记录
