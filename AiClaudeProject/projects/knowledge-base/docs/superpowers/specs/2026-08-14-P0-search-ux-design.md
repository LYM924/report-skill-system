# 智能知识库服务 - P0 搜索体验优化设计

日期：2026-08-14

## 概述

对智能知识库搜索服务进行 P0 核心体验优化，包括**搜索结果显示优化**和**大模型总结集成**。目标：从"能搜"变成"好用"。

## 架构

```
App.jsx (状态提升: searchResults, aiSummary, selectedDoc)
├── TopNav        (不动)
├── LeftSidebar   (不动)
├── CenterContent (重点改动)
│   ├── 搜索栏
│   ├── 快捷按钮 (大模型总结 改为功能入口)
│   ├── AI 总结面板 (新增)
│   │   ├── 自动摘要 (流式)
│   │   └── 深度分析 (手动触发)
│   ├── 搜索结果卡片列表 (重写)
│   │   ├── FAQ 匹配组
│   │   ├── 产品文档组
│   │   └── 报表数据组
│   └── 知识总览 (保留)
└── RightPanel (功能增强)
    ├── 默认: 高频FAQ + 最近更新
    └── 选中文档: 文档详情视图 (带返回按钮)
```

## 功能设计

### 1. 搜索结果显示优化

#### 1.1 结果卡片化

每条结果一张卡片，包含：
- **标题**：可点击，点击后在右侧面板展示完整文档内容
- **高亮摘要**：匹配关键词用 `<mark>` 高亮
- **来源面包屑**：如"数智财务组 > 浙里报 > 2025-10_版本迭代.md"
- **相关度**：百分比标签（基于 BM25 分数归一化）
- **类型标签**：📄产品文档 / ❓FAQ / 📊报表

#### 1.2 按类型分组

搜索结果按来源分三个可折叠区：
- FAQ 匹配（优先展示，直接解答问题）
- 产品文档
- 报表数据

每组显示命中数量，默认全部展开。

#### 1.3 交互增强

- 关键词在摘要中高亮
- 点击卡片 → 右侧面板展示文档详情
- 一键复制链接
- 无结果时展示搜索建议

### 2. 大模型总结集成

#### 2.1 自动摘要

搜索后自动调用 `/api/claude-stream`（SSE），在结果列表上方流式展示：
- 问题直接回答
- 关键信息摘要（2-3 句）
- 参考文档列表

#### 2.2 深度分析

摘要下方显示"展开深度分析"按钮，点击后：
- 发送更详细的 prompt（含更多上下文文档）
- 流式输出完整分析报告
- 包含：问题拆解、分点回答、操作建议、关联 FAQ

#### 2.3 状态管理

- 流式输出时显示打字光标动画
- 加载中骨架屏
- 出错时显示重试按钮

### 3. 右侧面板增强

- **默认状态**：保持现有的高频 FAQ + 最近更新
- **选中文档后**：切换为文档详情视图
  - 标题、元信息（模块、部门、更新时间）
  - 完整 Markdown 内容渲染
  - 关联 FAQ 列表
  - 返回按钮切回默认视图

## 数据流

```
用户搜索 → searchKnowledge API → 后端返回结果 + SSE URL
  → 自动调用 /api/claude-stream → 流式渲染 AI 总结
  → 同时渲染结果卡片列表
  → 用户点击卡片 → getDocumentDetail API → 右侧面板展示
```
