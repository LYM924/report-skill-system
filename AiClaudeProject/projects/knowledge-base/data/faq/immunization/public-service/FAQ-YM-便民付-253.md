# 受种者有哪些支付方式可以选？

## 问题描述

受种者有哪些支付方式可以选？

## 解决方法

共有3种支付方式（见右图）：医保支付、自费支付、线下支付/现金收款，系统自动带入本次登记需支付的疫苗
1、医保支付包括：医保实体卡、电子医保码（可配置）
1.1 医保实体卡：需要先点击“读卡”，再引导受种者插卡。注意：如为异地医保卡，可能会因地方政策差异导致无法正常结算，提示“预结算失败”（如下图所示），此时门诊需反馈HIS系统排查
1.2 电子医保码：需先点击“扫码”，再引导受种者扫码。
注意：1、如为儿童接种，需使用儿童医保码共济账户进行验证。使用家长医保码将会无法正常支付。2、新生儿如首次接种未上户口的情况，可能会导致电子医保码扫码无法成功，需使用实体卡插卡才可正常付款。

注意！如果没有点“读卡”/“扫码”，是读取不到医保信息的，也不会支付成功，会报错

1-2、自费支付包括：支付宝、微信、HIS厂商对接的聚合支付渠道（可配置）
备注：档案身份证号是18个8不支持使用医保，只能使用自费方式

1-3、线下/现金：门诊直接点【确定】>【我知道了】，预防接种与HIS系统打通，会传输数据给HIS
