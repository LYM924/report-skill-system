# Q：产科门诊如何操作新生儿转院？

## 问题描述

Q：产科门诊如何操作新生儿转院？

## 解决方法

A：预防接种>档案管理>转院档案>新增转院档案 允许将新生儿的转院信息录入本产科门诊，并支持对这些档案进行编辑和疫苗接种管理。备注：仅3个月内新生儿支持转院操作。

## 排查要点

2. 按照解决方案步骤逐一排查
3. 如问题未解决，提交技术支持工单
