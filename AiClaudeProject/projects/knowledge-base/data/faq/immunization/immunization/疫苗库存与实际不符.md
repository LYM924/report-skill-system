# 疫苗库存与实际不符

## 问题描述

疫苗馆库存数据与实际库存数量不一致，系统库存少于或多于实物库存，影响疫苗接种和库存管理。

## 原因分析

共 6 种可能原因，按常见程度排列：

| # | 原因 | 说明 | 偏差方向 |
|---|------|------|----------|
| 1 | 入库记录未及时录入 | 疫苗到货已入库但未在系统中做入库操作 | 系统库存 < 实际库存（负偏差） |
| 2 | 出库记录未及时录入 | 接种使用后未在系统中做消减操作 | 系统库存 > 实际库存（正偏差） |
| 3 | 疫苗报损未录入系统 | 过期、破损、变质疫苗已实物处置但未做报损登记 | 系统库存 > 实际库存（正偏差） |
| 4 | 入库/出库数量录入错误 | 操作时数量录入有误（如 100 支录入为 10 支） | 系统库存异常（偏差方向不定） |
| 5 | 疫苗移库未记录 | 疫苗在不同冷库、接种点或院区之间转移后未在系统中做移库操作 | 系统库存异常（移出地正偏差，移入地负偏差） |
| 6 | 数据同步延迟（多系统） | 疫苗馆与其他系统（如 HIS、省平台）之间数据同步未完成 | 临时性偏差，通常自动恢复 |

## 解决方法

### 方案一：库存盘点与核对流程

1. **准备盘点清单**
   - 进入【疫苗馆】→【库存管理】→【库存盘点】
   - 导出当前系统库存清单（含疫苗名称、批号、有效期、系统数量）

2. **实物盘点**
   - 按疫苗品种分类清点实物库存
   - 使用盘点单逐项核对，记录每项实物的实际数量
   - 特别注意同一疫苗不同批号需分开清点

3. **比对差异**
   - 逐一比对系统数量与实际数量，记录差异项
   - 差异计算公式：`差异 = 实际数量 - 系统数量`
   - 正差异（实际 > 系统）：说明有未入库或未调拨的记录
   - 负差异（实际 < 系统）：说明有未出库或未报损的记录

4. **生成盘点报告**
   - 在系统中录入盘点结果
   - 系统自动生成盘点差异报告
   - 报告路径：【疫苗馆】→【库存管理】→【盘点记录】→【查看报告】

### 方案二：常见偏差类型处理

**1. 入库遗漏（实际 > 系统，正偏差）**
- 检查近期的疫苗到货记录和物流单
- 在【入库管理】中补录遗漏的入库单
- 补录时需填写：疫苗名称、批号、生产企业、数量、有效期、入库日期

**2. 出库遗漏（实际 < 系统，负偏差）**
- 检查近期的接种记录，确认已使用但未消减的疫苗
- 在【出库管理】中补录出库记录，关联对应的接种记录
- 补录时需填写：疫苗名称、批号、数量、使用日期、接种人

**3. 报损遗漏（实际 < 系统，负偏差）**
- 检查过期、破损、温度异常等需报损的疫苗
- 在【报损管理】中录入报损记录
- 报损需填写：报损原因（过期/破损/其他）、数量、处置方式、处置日期
- 报损记录需审核通过后方可生效

**4. 移库遗漏（库存异常）**
- 检查近期的冷库间、接种点间调拨记录
- 在【移库管理】中补录移库操作
- 移库需填写：移出库房、移入库房、疫苗名称、批号、数量、移库日期

### 方案三：联系管理员进行库存校正

当差异原因不明或无法通过补录操作解决时：

1. 整理盘点差异报告（方案一生成）
2. 填写库存校正申请，说明差异原因和校正数量
3. 联系疫苗馆管理员（或系统运营人员）进行库存校正操作
4. 校正后再次盘点确认库存已恢复一致

**管理员联系方式：**
- 在系统内【帮助】→【联系我们】中查看当前区域运维人员联系方式
- 通过工单系统提交库存校正申请

## 排查要点

- [ ] 确认最近一次入库操作是否完整录入
- [ ] 确认最近一次出库操作是否完整录入
- [ ] 确认过期/破损疫苗是否已做报损处理
- [ ] 确认不同冷库或接种点之间是否有未记录的移库
- [ ] 核对疫苗批号是否正确，避免批号混淆导致数量偏差
- [ ] 检查是否存在同一疫苗多批号管理混乱的情况
- [ ] 查看系统操作日志，确认是否有异常操作记录
- [ ] 如为多系统间同步问题，确认各系统数据是否一致
