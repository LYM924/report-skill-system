# 接种记录同步延迟

## 问题描述

接种记录提交后，数据同步到省平台延迟超过 30 分钟，或在省平台查询不到已提交的接种记录。

## 原因分析

共 4 种可能原因，按常见程度排列：

| # | 原因 | 说明 | 典型特征 |
|---|------|------|----------|
| 1 | 同步队列积压 | 高峰期大量接种记录同时提交，超出队列处理能力，消息堆积导致延迟 | 系统整体响应慢，多条记录同时延迟，且本地保存正常 |
| 2 | 省平台接口响应慢或故障 | 省平台系统繁忙、接口限流或服务异常，导致数据推送失败或超时 | 仅同步到省平台延迟，本地保存正常，其他网络请求正常 |
| 3 | 本地网络波动 | 接种点网络不稳定、VPN 中断或防火墙限制访问省平台接口 | 伴有其他网络请求失败现象，如页面加载慢、图片加载失败 |
| 4 | 数据校验失败 | 接种记录数据格式或内容不符合省平台接口规范，被省平台拒收 | 特定记录同步失败，其他记录正常，通常在系统日志中有明确错误码 |

## 解决方法

### SLA 说明

接种记录同步到省平台的标准延迟时间（SLA）为 **30 分钟以内**。超过 30 分钟仍未同步成功，视为异常，需按以下流程排查。

### 方案一：区分网络问题与省平台问题

1. 在接种点访问其他网络服务（如搜索引擎、内部系统），确认网络是否正常
2. 如网络正常，尝试登录省平台管理端，确认省平台服务是否可用
3. 如省平台不可用，联系省平台运维人员确认平台状态
4. 如网络和省平台均正常，进入方案二排查队列状态

**快速判断参考：**
- 网络问题：同一时间所有网络请求均失败，伴有页面加载失败
- 省平台问题：本系统其他功能正常，仅同步任务失败，错误日志中返回省平台 HTTP 502/503
- 队列问题：系统操作正常，但同步状态持续显示"待同步"或"同步中"

### 方案二：检查同步队列状态

1. 进入【系统管理】→【同步监控】或【数据同步】功能
2. 查看同步队列当前积压数量（Pending 数量）
3. 查看队列处理速率（Processed/sec），判断是否正常消费
4. 查看失败记录列表，确认是否有特定记录反复失败

**队列状态解读：**
- 积压量 < 100 条：正常范围，等待自动消费即可
- 积压量 100-500 条：轻度积压，通常 30 分钟内可恢复
- 积压量 > 500 条：严重积压，需联系运维扩容

### 方案三：升级路径（超过 30 分钟仍未恢复）

1. 确认队列积压情况和省平台状态（方案一、二）
2. 如队列积压严重（> 500 条），联系运维人员扩容同步队列消费者
3. 如省平台接口异常，联系省平台技术支持确认接口恢复时间
4. 如为持续网络问题，联系网络管理员检查 VPN 或专线状态
5. 如为特定记录失败，查看错误日志并将错误信息发给开发人员分析

## 排查要点

- [ ] 确认最后一次成功同步的时间点
- [ ] 确认当前系统与省平台之间网络是否连通（ping 省平台地址或 telnet 端口）
- [ ] 查看同步队列积压数量（系统监控页面）
- [ ] 查看省平台管理端是否正常可访问
- [ ] 查看系统错误日志，确认是否有 HTTP 502/503/504 或超时错误
- [ ] 检查是否只有特定接种点/特定记录同步失败（数据校验问题）
- [ ] 确认同步延迟是否超过 SLA 标准（30分钟）
