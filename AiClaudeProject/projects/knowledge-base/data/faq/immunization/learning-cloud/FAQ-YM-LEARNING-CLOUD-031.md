# 为什么我实际学习的课程比我的岗位多？

## 问题描述

为什么我实际学习的课程比我的岗位多？

## 解决方法

1、联系单位业务管理员删除无关权限
2、如删除后发现还是有很多无关视频，客服提交技术工单
话术：老师，您被分配了什么岗位，系统就会自动分配学习任务的

## 排查要点

1. 确认用户描述的问题场景是否与上述一致
2. 按照解决方案步骤逐一排查
3. 如问题未解决，提交技术支持工单
