# Q：免疫规划学习云模块可以看到课程任务，但是进入课程详情会报错“没有学习权限”？

## 问题描述

Q：免疫规划学习云模块可以看到课程任务，但是进入课程详情会报错“没有学习权限”？

## 解决方法

原因是用户变更过手机号，客服需收集以下信息，提交技术工单处理
1、采云学院无法观看的课程全屏截图
2、采云学院个人信息中的手机号
3、新手机号、旧手机号

## 排查要点

1. 确认用户描述的问题场景是否与上述一致
2. 按照解决方案步骤逐一排查
3. 如问题未解决，提交技术支持工单
