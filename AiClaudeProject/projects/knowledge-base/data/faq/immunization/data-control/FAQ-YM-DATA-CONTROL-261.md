# 8剂次接种率统计规则是什么？

## 问题描述

8剂次接种率统计规则是什么？

## 解决方法

数据统计周期为2025年，统计8剂次接种率（其中7剂次——乙肝第3剂、卡介苗、脊灰第3剂、百白破第3剂、含麻疫苗第1剂、A群流脑第2剂、乙脑第1剂——取自两岁出生队列，甲肝1剂次取自三岁出生队列），每月3日、10日、17日、24日自动跑数计算更新，单剂次应种人数为0时标记“-”并视为达标（如门诊无个案或个案已迁出情况），若所有8剂次接种率均≥90%则整体判定“是”，否则“否”。
