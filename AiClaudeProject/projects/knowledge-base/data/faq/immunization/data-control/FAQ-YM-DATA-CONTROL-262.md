# 如何查看和导出8剂次接种数据？

## 问题描述

如何查看和导出8剂次接种数据？

## 解决方法

在数据智控→接种率监测→8剂次接种率页面，疾控用户（省/市/区县）可查看辖区多级汇总数据（省→市→区县→街道→门诊）并支持按省、地市、区县、街道、接种单位五级钻取，门诊用户仅查看本单位数据，所有用户均可在此页面查看并导出Excel报表。
