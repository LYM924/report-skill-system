# 接种证打印时会打印出系统网址

## 问题描述

用户在打印接种证时，打印出来的纸张上会显示系统网址（如浏览器地址栏中的 URL），影响接种证的正式性和美观。

## 原因分析

浏览器默认打印设置中开启了"页眉和页脚"选项，导致打印时自动添加网址、页码、日期等信息。

## 解决方法

### 方案一：关闭浏览器页眉页脚（推荐）

1. 在浏览器中点击打印（Ctrl+P 或 Cmd+P）
2. 在打印预览页面找到"更多设置"或"高级设置"
3. 找到"页眉和页脚"选项，取消勾选
4. 确认后重新打印

### 方案二：更换推荐浏览器

如上述方法无效，建议使用以下浏览器：
- Google Chrome（推荐）
- Microsoft Edge
- 360 浏览器极速模式

## 排查要点

1. 确认打印设置中"页眉和页脚"是否已关闭
2. 检查浏览器版本是否过旧，建议升级到最新版本
3. 如使用 IE 浏览器，建议更换为 Chrome 或 Edge
