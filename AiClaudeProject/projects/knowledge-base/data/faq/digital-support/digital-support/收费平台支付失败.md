# 收费平台支付失败

## 问题描述

用户在收费平台发起支付时，系统提示支付失败，具体表现为：支付页面加载失败、支付密码输入后返回错误、支付成功后系统未回调更新订单状态、或特定支付渠道（微信/支付宝/银行）无法使用。涉及线上一键支付和线下扫码支付两种场景。

## 原因分析

### 通用原因

| # | 原因 | 说明 |
|---|------|------|
| 1 | 支付通道异常 | 微信、支付宝、银行等支付通道服务不可用，或通道配置（商户号、密钥、证书）失效 |
| 2 | 账户余额不足 | 用户支付账户余额不足以支付订单金额 |
| 3 | 支付限额超限 | 单笔限额 / 单日累计限额 / 单月累计限额超出支付渠道或银行限制 |
| 4 | 商户配置异常 | 商户号未启用、密钥过期、回调地址未配置或配置错误、费率变更未同步 |
| 5 | 网络连接超时 | 用户端网络不稳定导致支付请求未到达支付通道，或支付通道回调未到达收费平台 |
| 6 | 订单状态异常 | 订单已支付 / 已取消 / 已退款，重复支付请求被拦截 |

### 各支付渠道特定错误码

| 渠道 | 错误码 | 含义 | 处理方式 |
|------|--------|------|----------|
| 微信支付 | INVALID_REQUEST | 请求参数缺失或格式错误 | 检查必填参数是否完整 |
| 微信支付 | PAY_ACCOUNT_NOT_EXISTS | 商户号未配置或已注销 | 联系管理员检查商户号状态 |
| 微信支付 | ORDER_CLOSED | 订单已关闭 | 重新生成订单 |
| 微信支付 | TRADE_OVERDUE | 订单已过期（二维码 30 分钟有效） | 重新生成支付二维码 |
| 微信支付 | NO_AUTH | 用户无支付权限（如账户未实名） | 引导用户完成微信实名认证 |
| 支付宝 | isv.invalid-app-id | 应用 ID 无效 | 联系管理员检查支付宝应用配置 |
| 支付宝 | isv.invalid-signature | 签名验证失败 | 检查密钥是否更新，重新同步密钥 |
| 支付宝 | ACQ.TRADE_NOT_EXIST | 交易不存在 | 确认订单号是否正确 |
| 支付宝 | ACQ.PAYMENT_NOT_ALLOW | 支付受限（如账户风控） | 引导用户联系支付宝客服解限 |
| 银行通道 | B0001 | 银行系统繁忙 | 稍后重试 |
| 银行通道 | B0002 | 银行卡余额不足 | 更换银行卡或充值 |
| 银行通道 | B0003 | 银行卡已过期或挂失 | 更换银行卡 |
| 银行通道 | B0004 | 单日累计交易限额超限 | 分日支付或联系银行提高限额 |
| 银行通道 | B0005 | 交易金额超限（单笔） | 降低单笔金额或分多次支付 |

## 解决方法

### 方案一：通用排查步骤

1. 确认当前使用的支付通道是否正常
   - 检查微信/支付宝/银行官方服务状态公告
   - 尝试切换其他支付通道（如微信失败换支付宝）
2. 确认用户账户余额是否充足
3. 确认支付金额是否在限额范围内
   - 单笔限额：通常微信/支付宝为 50000 元，银行通道视卡种而定
   - 单日限额：通常为 100000 元（可联系银行调整）
   - 单月限额：视账户等级而定
4. 清理浏览器缓存或切换网络环境（如从 4G 切换到 Wi-Fi）
5. 退出重新登录收费平台后重试

### 方案二：微信支付失败处理

1. 检查商户配置：
   - 进入收费平台后台 →「支付配置」→「微信支付」
   - 确认商户号（mch_id）状态为「启用」
   - 确认 API 密钥（APIv3 密钥）未过期
   - 确认回调地址（notify_url）配置正确且可访问
2. 微信支付失败错误码对照处理：
   - `INVALID_REQUEST`：检查订单金额、商品描述等参数是否符合微信支付接口规范
   - `ORDER_CLOSED`：订单已关闭，需重新创建订单
   - `TRADE_OVERDUE`：二维码已过期，需重新生成二维码
   - `NO_AUTH`：提示用户完成微信支付实名认证
3. 联系数字化支撑组修复商户配置（如密钥或商户号异常）

### 方案三：支付宝支付失败处理

1. 检查商户配置：
   - 进入收费平台后台 →「支付配置」→「支付宝」
   - 确认应用 ID（app_id）状态为「启用」
   - 确认应用私钥和支付宝公钥配置正确且未过期
   - 确认回调地址（notify_url）配置正确
2. 支付宝支付失败错误码对照处理：
   - `isv.invalid-app-id`：联系管理员重新获取有效应用 ID
   - `isv.invalid-signature`：重新同步密钥，确保公私钥配对
   - `ACQ.TRADE_NOT_EXIST`：检查传入的订单号是否正确
   - `ACQ.PAYMENT_NOT_ALLOW`：引导用户联系支付宝客服（95188）解限
3. 联系数字化支撑组检查支付宝应用配置是否更新

### 方案四：银行通道支付失败处理

1. 检查商户配置：
   - 进入收费平台后台 →「支付配置」→「银行通道」
   - 确认商户号状态为「启用」
   - 确认银行证书未过期、未吊销
   - 确认银行接口地址配置正确
2. 银行通道支付失败错误码对照处理：
   - `B0001`（银行系统繁忙）：稍后 5-10 分钟重试
   - `B0002`（余额不足）：建议用户更换银行卡或充值
   - `B0003`（卡过期/挂失）：建议用户联系发卡行或更换银行卡
   - `B0004`（单日累计超限）：分日支付，或联系银行临时提高限额
   - `B0005`（单笔超限）：将金额拆分为多笔支付
3. 如以上处理无效，联系银行接口运维人员排查

### 方案五：订单状态异常处理

1. 进入收费平台 →「订单管理」
2. 查询目标订单的当前状态
3. 如订单状态为「已支付」但用户反馈未收到服务——检查回调是否正常，手动触发补单
4. 如订单状态为「已取消」或「已退款」——告知用户需重新下单
5. 如订单状态为「支付中」超过 30 分钟——联系管理员确认支付通道是否正常回调

## 排查要点

1. [ ] 记录支付失败时的具体错误提示和错误码
2. [ ] 确认是哪条支付通道失败（微信 / 支付宝 / 银行）
3. [ ] 检查商户配置是否正常（商户号、密钥、回调地址、证书）
4. [ ] 确认用户账户余额是否充足
5. [ ] 确认订单金额是否超过单笔 / 单日 / 单月限额
6. [ ] 检查网络连接是否稳定
7. [ ] 确认订单状态是否正常（未支付 / 未取消 / 未过期）
8. [ ] 尝试切换支付通道验证是否通行
9. [ ] 如涉及银行通道，确认银行卡状态正常（未过期 / 未挂失）
