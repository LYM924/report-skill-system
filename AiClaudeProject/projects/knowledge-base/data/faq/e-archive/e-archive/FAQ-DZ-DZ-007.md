# 记账凭证传输后核算云查不到

## 问题描述

用户在浙里报操作"记账凭证传输"后，核算云侧查不到数据。用户反复联系浙里报和核算云，双方互相推诿，问题长时间得不到解决。

## 原因分析

记账凭证传输链路为 `浙里报 → 数新（中间库） → 核算云`：

| 原因类型 | 具体原因 |
|---------|---------|
| 核算云未拉取 | 数据已推送数新，但核算云未及时从数新拉取数据 |
| 支付渠道差异 | 国库集中支付的数据由一体化直接推送核算云，不走浙里报传输 |
| 传输时效 | 记账凭证推送后需次日 16:00 后核算云才能取到数据 |
| 区划编码问题 | 单位区划编码与核算云查询的区划不一致 |

## 解决方法

### 方案一：确认支付渠道

1. 查看报销单的支付方式
2. **国库集中支付**：数据由一体化直接推送核算云，在核算云查看即可，无需在浙里报操作凭证传输
3. **非财政资金**：在浙里报操作凭证传输后，联系核算云从数新拉取数据

### 方案二：等待次日查看

1. 记账凭证传输成功后，需等待次日 16:00 后
2. 核算云系统会自动从数新拉取数据
3. 次日登录核算云查看

### 方案三：联系核算云运维

1. 提供记账凭证传输截图（含传输时间、凭证编号）
2. 联系当地财政数字中心或核算云运维人员
3. 告知核算云从数新中间库拉取指定日期的凭证数据

## 排查要点

1. 浙里报不直接推送凭证给核算云，中间经过数新系统
2. 数据已推送成功的标志：浙里报显示"传输成功"
3. 核算云取数有时效性，当天传输的数据次日才能看到
4. 如单位区划编码不一致，需确认核算云查询的区划是否正确
