# 电子档案归档后无法检索

## 问题描述

用户在电子档案系统中完成档案归档操作后，在检索界面输入关键词无法找到已归档的档案，或搜索结果为空。可能出现在刚归档完成后立即检索，或跨时间段检索的场景。

## 原因分析

共 6 种可能原因，按常见程度排列：

| # | 原因 | 说明 |
|---|------|------|
| 1 | 索引尚未完成更新 | 档案归档后需要时间同步到搜索引擎索引，通常需 1-5 分钟，高峰期可能延长至 10-15 分钟。强制刷新索引可加速 |
| 2 | 检索关键词不匹配 | 系统默认对档案标题、档案编号、文号进行全文检索，如果仅输入正文内容关键词可能无法命中。档案命名不规范（如"新建文档.docx"）也会导致检索困难 |
| 3 | 档案权限不足 | 当前用户角色/部门无该档案的查阅权限。档案按「密级 + 部门 + 角色」三级权限模型控制，缺少任一维度授权即不返回结果 |
| 4 | 高级搜索条件冲突 | 使用高级搜索时，筛选条件（如日期范围、档案类型、密级等）组合后无匹配结果，或条件之间存在逻辑冲突 |
| 5 | 档案状态异常 | 归档过程中系统异常导致档案状态为「归档中」或「归档失败」而非「已归档」，此类档案不会出现在检索结果中 |
| 6 | 检索字段覆盖不全 | 部分早期版本归档的档案可能缺少自定义元数据字段，导致按自定义字段检索时无法命中 |

## 解决方法

### 方案一：强制刷新索引（首选）

适用于刚归档后检索不到的场景。

1. 进入电子档案系统 →「档案管理」→「索引管理」
2. 点击「强制刷新索引」按钮
3. 选择需要刷新的档案范围（全量 / 增量 / 指定档案编号）
4. 确认后等待系统提示「索引刷新完成」
5. 返回到检索页重新检索

> 注意：索引刷新期间检索功能不受影响，仅返回刷新前的索引数据。

### 方案二：检查并修正检索方式

1. 使用档案编号精确检索（最可靠方式）
   - 输入完整的档案编号，如 `DA-2026-08-001`
   - 支持模糊匹配：`DA-2026-08-*` 或 `DA-2026*`
2. 检查档案命名是否符合规范
   - 规范格式：`[档案类型]-[年度]-[序号]-[摘要]`
   - 如 `[合同]-[2026]-[001]-[年度IT服务合同]`
   - 不规范命名可能导致检索不到，建议重命名后重新归档
3. 清除搜索条件后重新搜索
   - 点击「重置」或「清除搜索条件」
   - 仅输入一个核心关键词尝试
   - 如仍无法检索，清空浏览器缓存或切换到无痕模式重试

### 方案三：检查档案权限设置

1. 联系档案管理员进入「权限管理」→「档案权限」
2. 确认当前用户角色是否在档案的可查阅角色列表中
3. 档案权限模型说明：
   - 密级维度：公开 / 内部 / 机密 / 绝密（用户需对应密级授权）
   - 部门维度：档案归属部门 vs 用户所属部门（跨部门需授权）
   - 角色维度：管理员 / 查阅者 / 预览者（不同角色检索范围不同）
4. 如权限不足，按流程提交档案权限申请工单

### 方案四：检查档案状态

1. 进入「档案管理」→「归档任务列表」
2. 查找目标档案的归档任务记录
3. 查看任务状态：
   - 如为「归档中」——等待任务完成
   - 如为「归档失败」——查看失败原因，修复后重新归档
   - 如为「已归档」——按方案一刷新索引后重试
4. 导出归档日志，检查是否有异常报错

## 排查要点

1. [ ] 确认档案是否已经归档完成（状态为「已归档」）
2. [ ] 使用档案编号进行精确检索，排除关键词因素
3. [ ] 执行强制刷新索引操作（索引管理→强制刷新）
4. [ ] 确认当前用户对目标档案有查阅权限
5. [ ] 检查是否开启了过多筛选条件导致零结果
6. [ ] 查看归档任务日志确认无异常报错
7. [ ] 如涉及跨部门档案，确认已提交跨部门查阅授权
