# 银行回单同步后电子档案不显示

## 问题描述

用户在浙里报-财务管理-银行回单页面点击"同步回单"后，电子档案-资料采集页面仍看不到银行回单，或回单数据不全。常见表现为：
- 某个月份的银行回单全部缺失
- 基本户回单有但零余额账户/公务卡专户回单缺失
- 授权支付回单有但收款回单缺失
- 新签约的银行账户回单不同步

## 原因分析

银行回单同步链路为 `银行 → 浙里办票（第三方平台） → 浙里报`，任一环节出问题都会导致回单缺失：

| 原因类型 | 具体原因 | 判断方法 |
|---------|---------|---------|
| 浙里办票侧 | 浙里办票拉取银行数据接口报错或延迟 | 联系浙里办票确认 |
| 银行侧 | 银行回单数据中缺少付款人信息等必填字段 | 提供回单编号给银行核实 |
| 银行侧 | 银行系统升级后回单格式变化，浙里办票未适配 | 确认银行近期是否有升级 |
| 历史数据 | 历史回单（超过3个月）需银行后台重新处理 | 检查回单时间范围 |
| 查询条件 | 用户筛选条件（付款银行/收款银行）过滤了部分回单 | 清空筛选条件重试 |

## 解决方法

### 方案一：手动同步（首选）

1. 进入 `财务管理 → 银行回单` 页面
2. 选择需要同步的时间段（建议每次不超过 7 天）
3. 点击"同步回单"按钮
4. 等待同步完成后刷新页面查看

### 方案二：检查筛选条件

1. 在银行回单列表页，清空付款银行和收款银行的筛选条件
2. 将"是否关联报销单"改为"全部"
3. 搜索回单编号确认回单是否已同步到浙里报

### 方案三：联系浙里办票同步

1. 提供以下信息给技术支持：银行账号、开户行、回单编号、回单时间范围
2. 技术支持联系浙里办票进行批量拉取同步
3. 用户次日手动点击同步查看

## 排查要点

1. 确认银行账户已在浙里办票完成签约授权（检查 `财务管理 → 银行账户管理` 中授权状态）
2. 确认回单的时间范围在银行签约授权之后（历史回单不会自动同步）
3. 提供具体的回单编号（可从银行 APP/网银获取）便于精确定位
4. 如为国库集中支付，回单直接同步给一体化，不回传浙里报
