# 归档后附件缺失或显示空白

## 问题描述

用户在核算云归档后，电子档案-资料采集页面中附件缺失或显示空白。常见表现为：
- 国库集中支付的授权支付回单在档案采集中缺失
- 其他资金场景的附件不同步
- 资产负债表/收入费用表内容为空
- 凭证附件预览时显示空白或"文件不存在"

## 原因分析

| 原因类型 | 具体原因 |
|---------|---------|
| 支付渠道差异 | 国库集中支付数据由一体化直接推送核算云，回单不回传浙里报 |
| 场景限制 | 其他资金场景目前不支持自动关联单据附件 |
| 采集时机 | 归档采集时间在银行回单同步之前，导致回单未纳入 |
| 核算云数据 | 核算云推送数据时内容为空（用户未在核算云维护） |
| 附件数量超限 | 单据附件数超过最大限制导致推送失败 |

## 解决方法

### 方案一：撤销归档重新操作

1. 在核算云撤销该月份归档
2. 先在财务管理-银行回单中同步缺失的回单
3. 重新发起归档
4. 次日查看电子档案

### 方案二：手动补充附件

1. 进入电子档案-资料采集页面
2. 找到对应档案记录，点击编辑
3. 手动上传缺失的附件（银行回单、凭证等）
4. 保存后即可查看

### 方案三：区分支付渠道

1. 国库集中支付的单据：回单和附件在核算云查看，不回传浙里报
2. 非财政资金的单据：确认已在浙里报完成回单同步后再归档
3. 其他资金场景：目前需手动上传附件

## 排查要点

1. 确认归档采集时间：如采集时间早于回单同步时间，需撤销重新归档
2. 检查附件数量：附件数不能超过最大限制（通常为 5 个）
3. 国库支付场景：附件在核算云侧，不在浙里报电子档案
4. 资产负债表等内容为空：需在核算云维护数据后重新推送
