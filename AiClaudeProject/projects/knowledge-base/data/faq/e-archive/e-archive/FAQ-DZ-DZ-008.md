# 银行回单关联凭证后取消再关联失败

## 问题描述

用户在财务管理-银行回单页面手工关联凭证后，电子档案中不显示回单；或频繁关联-取消关联后，再次关联时失败，无法完成关联操作。

## 原因分析

| 原因类型 | 具体原因 |
|---------|---------|
| 数据覆盖 | 手工关联回单到凭证后，数据可能被后续同步操作覆盖 |
| 操作限制 | 系统不支持频繁关联-取消-再关联操作，取消后再次关联会失败 |
| 凭证已关联 | 回单已关联了其他记账凭证，需先取消旧关联 |

## 解决方法

### 方案一：取消关联后重新操作

1. 在银行回单列表中找到该回单，点击"取消关联"
2. 刷新页面确认取消成功
3. 重新选择目标凭证进行关联
4. 刷新电子档案-资料采集查看

### 方案二：手动上传（兜底方案）

1. 如关联操作反复失败，进入电子档案-资料采集
2. 找到对应凭证，点击编辑
3. 手动上传银行回单文件作为附件
4. 保存后即可在电子档案中查看

### 方案三：撤销核算云归档重新操作

1. 在核算云撤销该月份归档
2. 重新归档
3. 回单关联会自动重建

## 排查要点

1. 避免频繁关联-取消操作，确认好目标凭证后再操作
2. 如回单已关联到其他凭证，需先取消旧关联
3. 手动上传的回单不会自动带结构化数据（交易金额、日期），需手动填写
