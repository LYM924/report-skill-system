# 报销单提交后审批流程卡住

## 问题描述

报销单提交后，审批流程长时间停留在某一节点未推进，界面显示「审批中」但无变化，超过预期时间（通常超过 2 个工作日）仍未到达下一节点或完成审批。

> **注意**：请先区分「卡住」与「慢」——审批流程超过 2 个工作日无变化属于「卡住」；如果在 2 个工作日内推进，属于正常审批等待，请先联系审批人确认。

## 原因分析

共 6 种可能原因，按常见程度排列：

| # | 原因 | 说明 |
|---|------|------|
| 1 | 审批人休假未设置代理 | 当前审批节点负责人休假、出差或离职，且未设置代理审批人，导致审批单无人处理 |
| 2 | 审批流程配置错误 | 流程中某一节点未正确配置审批人（如角色为空、人员已离职但未更新），导致流程卡在该节点无法继续 |
| 3 | 审批节点条件不满足 | 该报销单触发了特定条件分支（如金额超过阈值需额外审批），但该分支节点未配置审批人 |
| 4 | 审批人已离职或调岗 | 审批人在系统中仍为有效状态，但实际已离职，审批单无法被处理 |
| 5 | 系统审批异常（审批节点异常跳过） | 审批流程引擎异常，导致节点状态异常，审批单无法自动推进（需查看审批日志确认） |
| 6 | 关联单据未完成 | 报销单关联的申请单或合同审批处于未完成状态，导致报销单审批被阻塞 |

## 解决方法

### 方案一：确认当前审批节点及审批人

1. 进入报销单详情页，查看「审批进度」或「流程图」
2. 记录当前审批节点名称及审批人姓名
3. 确认该审批人是否在职、是否在休假、是否已设置代理审批人
4. 如审批人不在岗，联系审批人本人或其上级，设置代理审批人或转交审批

### 方案二：查看审批流程日志

1. 登录运营后台 → 「流程管理」→ 「审批日志」
2. 输入目标报销单编号，查询审批日志
3. 查看日志中每个节点的审批状态（待审批 / 已通过 / 被驳回 / 异常跳过）
4. 重点关注日志中是否有「节点异常」「跳过」「错误」等标记
5. 根据日志信息定位问题节点

### 方案三：超时处理与人工干预

1. 如果审批单在同一节点停留超过 2 个工作日，定义为「卡住」
2. 以下情况可联系运营进行人工干预：
   - 审批人不在岗且无代理审批人
   - 审批流程配置错误（如节点审批人为空）
   - 审批日志显示异常跳过
3. 运营同学可在后台手动转交审批或重新激活流程

### 方案四：检查关联单据状态

1. 确认报销单是否关联了申请单或合同
2. 检查关联单据的审批状态是否已完成
3. 如关联单据未完成，需先完成关联单据的审批
4. 关联单据完成后，报销单审批会自动推进

## 排查要点

- [ ] 确认是「卡住」（>2 个工作日无变化）还是「慢」（<2 个工作日但有推进）
- [ ] 查看审批流程图，确认当前停留的审批节点
- [ ] 确认当前审批人是否在职、是否在休假
- [ ] 确认审批人是否设置了代理审批人
- [ ] 查看审批日志，检查是否有异常标记
- [ ] 检查报销单关联的申请单/合同审批状态
- [ ] 确认流程配置是否完整（审批人角色是否为空）
- [ ] 如涉及金额条件分支，确认金额是否触发特殊审批节点
