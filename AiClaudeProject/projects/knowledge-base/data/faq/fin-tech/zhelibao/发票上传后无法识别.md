# 发票上传后无法识别

## 问题描述

在浙里报中上传发票（拍照或扫描件）后，系统未自动识别出发票信息，提示「识别失败」「未识别到有效发票」或长时间无响应，导致无法自动填单创建报销单。

## 原因分析

共 6 种可能原因，按常见程度排列：

| # | 原因 | 说明 |
|---|------|------|
| 1 | 图片清晰度不足 | 拍照时抖动、光线不足、角度倾斜导致发票号码、金额、二维码区域模糊，OCR 无法准确识别（错误码：OCR-1001） |
| 2 | 发票信息被遮挡 | 发票上存在水印、手写批注、粘贴痕迹或折叠遮挡了关键区域（左上角二维码、发票号码、金额区域） |
| 3 | 文件格式/大小不支持 | 上传文件格式非 JPG/PNG/PDF（如 HEIC/BMP/TIFF），或单张图片超过 10MB 限制 |
| 4 | OCR 服务异常 | 浙里报 OCR 识别服务临时故障或维护中，表现为多张发票均无法识别（错误码：OCR-5001/OCR-5002） |
| 5 | 发票类型不支持 | 上传的发票类型（如非税票据、财政票据特定格式、电子发票部分版式）不在浙里报当前支持的发票列表中 |
| 6 | 网络传输异常 | 上传过程中网络波动导致文件损坏或传输不完整，系统接收到的文件不可读 |

## 解决方法

### 方案一：重新上传清晰图片

1. 确认发票平整无遮挡，铺在白底或浅色桌面上拍摄
2. 确保光线充足，避免闪光灯反光或阴影遮挡发票号码
3. 手机保持与发票平行，正对拍摄，避免倾斜
4. 支持的格式：JPG、PNG、PDF；单张不超过 10MB
5. 重新上传，等待 3-5 秒查看识别结果

### 方案二：手动录入发票信息

1. 在发票上传页面，点击「手动录入」或「无法识别？点此手动录入」
2. 按发票实物逐项填写：
   - 发票类型（增值税发票/电子发票/财政票据/其他）
   - 发票号码
   - 发票代码
   - 开票日期
   - 不含税金额 / 税额 / 含税总金额
   - 销售方名称及纳税人识别号
   - 购买方名称及纳税人识别号
3. 点击「确认」保存
4. 手动录入的发票信息将参与后续报销单填单流程

### 方案三：OCR 服务异常处理

1. 确认是否多张发票同时无法识别 → 上传同一张发票在其他设备或浏览器重试
2. 如仍失败，可能是 OCR 服务异常：
   - 等待 10-15 分钟后重试
   - 联系数智财务组运营同学确认 OCR 服务状态
3. 如急需报销，先使用手动录入（方案二），后续再补传发票

### 方案四：发票类型确认

1. 查看浙里报支持的发票类型列表（运营后台 → 票据管理 → 发票类型配置）
2. 如上传的发票类型不在支持列表中，联系运营同学评估是否可扩展
3. 如为临时需要，使用手动录入并同步告知运营同学

## 排查要点

- [ ] 图片格式是否为 JPG/PNG/PDF（非 HEIC/BMP/TIFF）
- [ ] 单张图片是否超过 10MB
- [ ] 发票面是否平整、无遮挡、无折叠
- [ ] 发票号码和金额区域是否清晰可辨
- [ ] 其他设备/浏览器重试是否同样失败
- [ ] 近期是否有其他用户反馈类似问题（判断是否为 OCR 服务异常）
- [ ] 手动录入是否能正常保存
