# 预算指标同步失败

## 问题描述

在浙里报中发起预算指标同步（从财政一体化平台或预算编制系统同步至浙里报）时，同步失败，提示类似「同步异常」「指标编码不存在」「接口超时」等错误，或同步后指标数据未更新。

## 原因分析

共 6 种可能原因，按常见程度排列：

| # | 原因 | 说明 |
|---|------|------|
| 1 | 指标来源系统异常 | 财政一体化平台或预算编制系统临时维护或接口不可用，导致浙里报无法拉取指标数据。常见于月底/季末集中同步时段 |
| 2 | 指标编码不匹配 | 浙里报中配置的指标编码与来源系统不一致，可能因编码规则变更或录入错误导致同步匹配失败（错误码：E1001/E1002） |
| 3 | 同步接口超时 | 数据量过大或网络波动导致接口响应超时（默认超时阈值 30s），返回错误码 E2001（Timeout） |
| 4 | 指标状态异常 | 来源系统中的指标处于「已作废」「已冻结」或「已用完」状态，同步时被拦截（错误码：E3001/E3002） |
| 5 | 权限配置不足 | 同步操作账号在来源系统或浙里报中缺少指标同步权限 |
| 6 | 数据格式校验失败 | 来源系统返回的指标数据格式（如金额精度、日期格式、预算科目编码）与浙里报预期不匹配 |

## 解决方法

### 方案一：基础排查与手动触发同步

1. **确认来源系统状态**：登录财政一体化平台或预算编制系统，确认系统运行正常，无维护公告
2. **检查指标状态**：在来源系统中确认目标指标处于「已下达」「可用」等正常状态
3. **手动触发同步**：
   - 进入浙里报 → 「预算中心」→ 「指标同步」
   - 选择目标指标，点击「手动同步」
   - 观察同步结果提示，记录错误码
4. **查看同步日志**：在「同步日志」中查看最近一次同步的详细记录，定位失败步骤

### 方案二：指标编码核对与修正

1. 登录浙里报 → 「预算中心」→ 「指标配置」
2. 对比浙里报中配置的指标编码与来源系统中的编码是否一致
3. 如不一致，点击「编辑」修正编码后保存
4. 重新执行手动同步

### 方案三：接口超时处理

1. 确认同步数据量是否过大（如单次包含超过 500 条指标记录）
2. 如数据量过大，联系运营或管理员分批同步（每批建议不超过 200 条）
3. 检查网络环境，确认浙里报与来源系统之间网络连通性正常
4. 通知运营在后台调整超时配置（需同步调整接口超时阈值）

### 方案四：联系管理员处理

若以上方案均无法解决：

1. 记录错误码和同步时间
2. 联系数智财务组运营同学（浙里报运营群 / 工单系统）
3. 提供以下信息：
   - 来源系统名称及指标编码
   - 浙里报指标配置截图
   - 同步日志中的错误信息
   - 同步时间点

## 排查要点

- [ ] 来源系统（财政一体化平台/预算编制系统）是否正常运行
- [ ] 指标编码在浙里报与来源系统中是否一致
- [ ] 同步日志是否有超时记录（错误码 E2001）
- [ ] 指标状态是否为「已下达」「可用」（非作废/冻结）
- [ ] 同步操作账号是否具备指标同步权限
- [ ] 单次同步数据量是否超过 200 条
- [ ] 近期有无指标编码规则变更
