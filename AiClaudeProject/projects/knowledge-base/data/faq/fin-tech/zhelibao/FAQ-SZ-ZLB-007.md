# 报销单收款账户选不到

## 问题描述

用户在创建报销单时，选择收款账户时找不到目标账户。常见场景：
- 公务出行报销单选不到收款人
- 对公付款选不到收款账户
- 已在"收款账户管理"中添加了账户但报销单中选不到

## 原因分析

| 原因类型 | 具体原因 |
|---------|---------|
| 菜单位置错误 | 个人报销的收款账户需在"公务卡管理"或"银行账户"中维护，而非"收款账户管理" |
| 出差人限制 | 差旅报销单的收款人列表根据出差人筛选，只有出差人本人的账户可选 |
| 对公vs个人 | "收款账户管理"是对公付款用的，个人报销在"个人中心-银行账户"维护 |
| 账户被删除 | 收款账户被删除后重新支付时匹配不到 |

## 解决方法

### 方案一：确认维护位置

1. **个人报销**（差旅/公务出行）：在 `个人中心 → 银行账户` 或 `财务管理 → 公务卡管理` 中维护
2. **对公付款**：在 `财务管理 → 收款账户管理` 中维护
3. 维护后返回报销单页面刷新重新选择

### 方案二：检查出差人

1. 差旅报销单的收款人列表根据报销单中填写的出差人自动筛选
2. 确认出差人已在系统中维护了银行账户信息
3. 如出差人未维护，需先引导其维护后重新选择

### 方案三：重新选择

1. 删除已选的收款账户
2. 在收款人选择列表中重新搜索
3. 如仍找不到，确认账户信息是否正确维护

## 排查要点

1. 三个菜单位置的区别：公务卡管理（个人差旅）、银行账户（个人中心）、收款账户管理（对公付款）
2. 差旅报销单收款人由出差人决定，非出差人账户不可选
3. 账户维护后需刷新页面才能生效
