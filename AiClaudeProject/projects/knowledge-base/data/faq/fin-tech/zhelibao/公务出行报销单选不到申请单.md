# 公务出行报销单选不到申请单

## 问题描述

在浙里报中创建公务出行（差旅）报销单时，关联申请单的选择列表中找不到目标申请单。

## 原因分析

共 7 种可能原因，按常见程度排列：

| # | 原因 | 说明 |
|---|------|------|
| 1 | 申请单未审批通过 | 申请单必须处于「审批通过」状态才能被报销单关联 |
| 2 | 申请单已被关联使用 | 固定场景的申请单仅可被关联一次，已被其他报销单关联后不再显示 |
| 3 | 场景类型不匹配 | 公务出行报销单只能关联公务出行申请单，不能跨场景 |
| 4 | 申请单金额已被用完 | 申请单预算金额已被之前报销单全部占用 |
| 5 | 经办人不一致 | 申请单与报销单的经办人需匹配或有相应权限 |
| 6 | 关账期间限制 | 财务关账期间可能限制报销单创建或关联 |
| 7 | 申请单被标记"无需报销" | 经办人标记后不再出现在选择列表（详见下方） |

## 解决方法

### 第 1-6 条：常规排查

1. 确认申请单状态是否为「审批通过」
2. 确认申请单是否已被其他报销单关联
3. 确认申请单和报销单场景类型一致
4. 确认申请单预算金额未被用完
5. 确认经办人权限匹配
6. 确认不在关账期间

### 第 7 条：申请单被标记"无需报销"

公务出行申请单审批完成后，如果不需要报销，经办人可通过以下两种方式标记"无需报销"：

**方式一：从已完成列表操作**
1. 进入「我的单据」→「已完成」
2. 找到目标申请单
3. 点击「更多操作」→「无需报销」

**方式二：从报销单创建页面操作**
1. 创建报销单 → 关联申请单时
2. 在申请单操作模块点击「无需报销」

标记后，该申请单将**不再出现在创建报销单时的申请单选择列表中**。如果误操作，需联系管理员或运营同学撤销。

## 排查要点

1. 优先确认申请单是否在「已完成」列表中
2. 检查是否被标记过"无需报销"（查看操作记录）
3. 确认申请单状态和关联状态
