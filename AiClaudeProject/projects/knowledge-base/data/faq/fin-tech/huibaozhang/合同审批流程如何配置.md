# 合同审批流程如何配置

## 问题描述

在徽报账系统中，如何配置合同审批流程？具体字段含义是什么？需要哪些前置条件？审批流程如何按合同金额、类型等条件自动路由到不同审批层级？

## 原因分析

合同审批流程需要在徽报账运营后台进行配置，系统支持按合同金额区间、合同类型（采购/销售/框架协议等）、部门等条件设置多级审批节点。配置不完整或条件冲突会导致审批无法正常流转。

## 解决方法

### 前置条件

在配置合同审批流程之前，需要确认以下条件已满足：

1. **运营后台权限**：账号需具备「流程管理 → 合同审批流程」的配置权限（如无权限，联系数智财务组运营管理员开通）
2. **审批人角色已配置**：需要配置的审批人（财务主管、部门负责人、分管领导等）已在系统中维护并处于在职状态
3. **合同类型已定义**：合同类型字典（如采购合同、销售合同、框架协议、服务合同等）已在系统配置中维护

### 方案一：新增合同审批流程（标准配置）

1. 登录徽报账运营后台 → 「流程管理」→ 「合同审批流程」
2. 点击「新建流程」，填写以下字段：

| 字段 | 说明 | 示例 |
|------|------|------|
| 流程名称 | 审批流程的标识名称，建议按用途命名 | "采购合同审批流程（50万以上）" |
| 适用合同类型 | 选择该流程适用的合同类型，多选 | 采购合同、服务合同 |
| 适用部门 | 选择该流程适用的部门，可选「全部」 | 全部 / 具体部门 |
| 合同金额起 | 触发该流程的最低金额（含），0 表示不设下限 | 0 |
| 合同金额止 | 触发该流程的最高金额（含），空表示不设上限 | 500000 |
| 优先级 | 当多个流程匹配时，优先级高的生效 | 1（最高）- 99（最低） |

3. 配置审批节点（审批链），按顺序添加：

| 字段 | 说明 | 示例 |
|------|------|------|
| 节点序号 | 审批顺序，从 1 开始递增 | 1, 2, 3 |
| 节点名称 | 审批节点标识 | "部门负责人审批" |
| 审批人类型 | 角色 / 指定人员 / 部门负责人 / 上级 | 角色 |
| 审批人选择 | 选择具体的审批人或审批角色 | "部门负责人" 角色 |
| 通过条件 | 一人通过即通过 / 全部通过 | 一人通过即通过 |
| 是否允许驳回 | 该节点是否允许驳回申请 | 是 |

### 方案二：配置条件分支审批（按金额/类型路由）

1. 在「合同审批流程」页面，点击「条件分支配置」
2. 设置分支条件，例如：

| 条件 | 分支节点 |
|------|----------|
| 合同金额 ≤ 10 万 | 部门负责人审批 → 结束 |
| 10 万 < 合同金额 ≤ 50 万 | 部门负责人审批 → 财务主管审批 → 结束 |
| 合同金额 > 50 万 | 部门负责人审批 → 财务主管审批 → 分管领导审批 → 结束 |

3. 每个分支末尾可配置「结束节点」或「自动通过」
4. 保存后新流程即时生效

### 方案三：配置示例 — 采购合同审批链

以下为典型的采购合同审批链配置示例：

| 序号 | 节点名称 | 审批人类型 | 审批人 | 说明 |
|------|----------|------------|--------|------|
| 1 | 部门负责人审批 | 部门负责人 | 自动匹配 | 合同发起人所在部门负责人 |
| 2 | 财务主管审批 | 指定角色 | 财务主管 | 固定财务主管角色 |
| 3 | 分管领导审批 | 指定角色 | 分管领导 | 仅金额 > 50 万时触发（条件分支） |
| 4 | 法务审核 | 指定人员 | 法务专员 | 仅采购合同类型触发（条件分支） |

### 验证配置

1. 配置完成后，使用「测试流程」功能，输入测试合同金额和类型
2. 系统会显示匹配的审批流程和审批节点顺序
3. 确认无误后，用真实合同提交测试

## 排查要点

- [ ] 账号是否具备运营后台流程配置权限
- [ ] 审批人是否已在系统中维护且在职
- [ ] 合同类型字典是否已定义
- [ ] 金额区间设置是否有重叠或遗漏（如 0-10 万 和 10-50 万，边界值是重复还是互斥）
- [ ] 不同流程的优先级设置是否正确，是否有流程冲突
- [ ] 条件分支的节点是否都已配置审批人
- [ ] 测试流程是否能正确匹配到预期审批链
- [ ] 保存后是否已生效（未生效需检查是否点击了「发布」）
