# 一、【疫苗馆】疫苗商品接种服务费金额批量调整

**需求描述：①批量调整疫苗馆-库存管理-库存商品中非免疫规划疫苗类目下的疫苗的服务费金额为23元。②10月20日起的历史数据订正处理。服务费已记录为28元的，统一订正为23元。影响数范围：供应单管理、出库单管理、入库单管理、非免规疫苗财务报表、供应应付。**

**菜单路径：疫苗馆-库存管理-库存商品；供应单管理、出库单管理、入库单管理、非免规疫苗财务报表、供应应付。**

**权限范围：所有门诊及疾控**

**规则说明：①仅订正原本数据为28元的，原本数据为0或-的，不做处理。②订正数据范围，包含20号以前创建的业务单据，但实际产生服务费快照数据是在20号及以后。**

# 二、【基础能力】运营后台可进行配置短信条数、短信签名

**需求描述：①支持在运营后台-单位管理中，进行短信条数调整。②支持对于短信条数进行调增、调减。③在调整短信条数时，必须上传相关证明材料。④所有操作记录将会被记录，后续可进行查询。**

**菜单路径：运营后台-单位管理-操作-短信条数调整/短信签名调整**

**权限范围：运营账号**

**规则说明：调整时，必须要上传证明材料。**

# 四、【基础能力】疫苗馆-PDA登录增加图形验证码，降低被恶意盗刷登录短信风险

**需求描述：通过增加PDA登录增加图形验证码，降低被恶意盗刷登录短信风险**

**操作步骤：**

**步骤1：进入登录页面，选择手机验证码登录**

**步骤2：输入手机号**

**步骤3：输入图形验证码**

**步骤3-1：如未填写，则提示：请先填写验证码**

**步骤3-2：如已填写，则校验图形验证码的正确性，**

**步骤3-2-1：如正确，则提****示：若手机号无误，短信验证码已发送。**

**步骤3-2-2：如验证码错误，则提示：图形验证码错误，请重新输入。**

**步骤4：输入短信验证码，点击登录，完成登录。**
