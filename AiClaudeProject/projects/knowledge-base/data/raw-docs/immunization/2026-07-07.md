# 【免疫程序】HPV 疫苗接种，小年龄段人群，统一按最小月龄标准推荐接种。

## 1. 背景与目标

### 背景

当前 HPV 疫苗在小年龄组支持多种接种程序。例如默沙东九价 HPV 疫苗，首针接种年龄为 9-14 岁的女性，既可按 0、5 月两针法完成全程，也可按 0、2、6 月三针法完成全程。由于系统现阶段无法准确识别受种者实际选择的是两针法还是三针法，逾期未种、查验证、HPV专项统计等场景中的计划接种日期和全程状态可能不够精准。

现省疾控业务专家确认，小年龄组默认按两针法推荐，即按短月龄间隔 5 个月推荐第 2 针。

## 2. 用户、权限与入口

无变化，与之前保持一致。

## 4. 场景与功能规则

### 场景一：免疫程序规则配置与推荐引擎调整

*   入口：免疫程序配置、HPV 疫苗推荐服务、接种登记前置校验。
    
*   触发：受种者存在 HPV 首剂接种记录，且首剂疫苗编码和首剂年龄满足特殊年龄段规则。
    
*   差异化处理：
    
    *   系统默认按两针法生成下一针推荐，第 2 针计划接种日期为首针接种日期加 5 个月。
        
*   数据影响：推荐结果影响预约、逾期、未完成全程名单、查验证状态和 HPV 专项统计中的计划接种日期。
    

### 场景二：今日接种、下一针预约

*   入口：今日接种 / 登记管理；下一针预约；疫苗处方登记。
    
*   触发：登记或保存 HPV 接种记录后，系统重新计算下一剂次推荐。
    
*   差异化处理：
    
    *   符合特殊年龄段规则时，登记首剂后推荐第 2 剂次，计划日期按 5 个月间隔生成；
        
*   数据影响：预约记录、计划接种日期、处方登记校验和后续逾期判断同步变化。
    
*   结果口径：默认两针法推荐不影响医生按业务需要手工添加三针法剂次。
    
*   界面交互：
    
    *   间隔未满5个月时，智推不展示，手工添加支持选择

### 场景五：数据智控 HPV 专项与查询查验

*   入口：数据智控 / 接种率监测 / HPV 疫苗专项；查询查验 / 查验情况汇总 / HPV 疫苗查验。
    
*   触发：疾控用户查看 HPV 出生队列接种统计、查验汇总或查验明细。
    
*   差异化处理：
    
    *   全程人数、未完成全程人数、计划接种日期和查验状态按新免疫程序和查验规则计算。
        
*   数据影响：报表合计、下钻名单、导出文件、数据智控汇总均需同步新状态。
    

### 场景六：入托入学查验功能适配改造

**1、业务背景**

人乳头瘤病毒疫苗免疫程序调整后，入学入托查验证模块中HPV疫苗查验需要适配新的判定规则与状态展示口径。

本次调整不改变“全程接种”的定义，重点在于查验状态口径统一与去除需人工判断状态。

**2、范围（包含/不包含）**

包含：

入学入托查验证模块内与HPV相关的：

查验明细表

查验汇总报表

数据智控-查验数据汇总

不包含：

除HPV外的其他疫苗在入学入托查验证模块内的查验规则与状态口径。

本模块除“查验明细/汇总/质控汇总”以外的其他页面与功能点（需补充原型或页面清单后完善）。

**3、用户角色与权限范围**

所有使用入托入学查验功能的**接种门诊**

所有使用入托入学查验功能的**疾控机构**

**4、功能详情（本次变更点）**

**4-1、查验状态口径**

未查验：尚未触发查验或未生成查验结果

已全程接种：按免疫程序判断已完成全程接种（不区分国免/非国免、两针法/三针法）

未接种：未接种过任何HPV疫苗

未全程接种-间隔未到：未完成全程接种，且下一剂次应接种时间未到

未全程接种-已逾期：未完成全程接种，且下一剂次应接种时间已逾期

**4-2 查验规则**

情况1：未接种过任何HPV疫苗，查验结果为：未接种

情况2：已完成全程接种（按免疫程序判断），查验结果为：已全程接种

情况3：仅接种过1剂次 未全程接种-间隔未到 / 未全程接种-已逾期（见下方间隔规则）

情况3-1：国免    0-6间隔    当前时间与下一剂次应接种时间对比，输出“间隔未到/已逾期”

情况3-2：非国免    0-5间隔    当前时间与下一剂次应接种时间对比，输出“间隔未到/已逾期”

情况4：已接种2剂次但免疫程序未判定全程 未全程接种-间隔未到 / 未全程接种-已逾期；
