# 疫苗-浙里接种钉钉/浙政钉-首页改造

*   **菜单路径：浙政钉-卫健工作台-浙里接种-首页；钉钉-工作台-浙里接种-首页**
    
*   **权限范围：所有疾控、门诊；注意本次仅开启部分试点账号，试点完成后开通剩余地区。**
    
*   **需求描述：**
    
    *   对首页功能模块进行升级，支持以下数据内容
        
    *   【档案数据】全年龄段档案数据、0-6岁档案数据
        
    *   【今日接种数据】各分类下疫苗接种区情况；支持7/30天趋势查看。
        
    *   【接种门诊数据】当天有接种产生的门诊数量，且支持按门诊类型分布；支持7/30天趋势查看。
        
    *   【智慧便民元素数据】支持查看智慧便民元素的数据情况
        
    *   通用能力：支持按不同维度进行查看，全省、地市、区县、门诊
        
    *   数据范围控制：当前机构仅支持查看本级及下级数据。
        

步骤1：打开【浙里接种】应用，进入首页。

注意：首次登录需满足以下3个条件：

条件1：单位管理员已申请开通浙里接种移动端应用，且已由承建商公司完成后台配置。

条件2：账号在本地已存在且处于启用状态，且完成手机号验证。

条件3：当前账号已被授予【浙里接种移动端】权限
