# 便民付-门诊操作手册

# 一、业务场景&规则说明

## （一）业务场景

### 1、登记/支付场景

1-1、医保支付包括：医保实体卡、电子医保码

1-2、自费支付包括：支付宝、微信、HIS厂商对接的聚合支付渠道

1-3、线下/现金：

### 2、退款场景

2-1、通过HIS退款后，同步至预防接种系统

## （二）规则说明

### 1、疫苗匹配关系规则

规则1：预防接种系统通过接口传递HIS需要的数据项，由HIS在系统进行【收费项】存储，并在收费项中，关联对应的医保国码。

### 2、医保读卡规则

规则1：预防接种系统通过本地的DLL程序，进行读卡，读卡完成后，通过接口推送给HIS处理。

### 3、业数据匹配关系规则

规则1：通过HIS提供的支付单同步接口进行同步，同步完成后，根据HIS返回的唯一ID，进行关联。

规则2：当登记信息发生变更，将会自动将原数据作废，并重新调用接口，生成新的支付单。如登记信息，未发生变更，则会继续使用原有的支付单进行支付。

### 4、撤销规则

规则1：支付成功状态，不可撤销。需先完成退款后，才可撤销。

### 5、退款规则

规则1：退款需由HIS发起，HIS发起后，同步至预防接种系统。

### 6、对疫苗库存的影响

规则1：库存仅受是否登记及接种影响，与支付状态无关。

### 7、对接种流程的影响

是否完成支付，不影响接种流程，但会在接种台界面上，展示实时的疫苗支付状态，由门诊老师确认是否已完支付，并且判断是否可进行接种。

**8、关于接种服务费是否需支持医保历年账户支付的说明**

情况1：支持，可以使用医保历年账户，一笔直接支付完成。

情况2：不支持，医保支付完成疫苗费用后，需要再单独扫码支付28元接种服务费。

情况1：支付成功

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/meonaAkGZAr8nXxj/img/5f234b5a-033d-44d7-a01e-a956216e6e25.png)

情况2：支付失败

如支付失败，则可重新发起支付。

一般会有1-3分钟延迟，如3分钟后还未同步，联系技术支持或客服进行处理。

### 4、退款流程

流程说明

步骤1：受种者或其监护人需要退款，联系门诊【收费台】工作人员。

步骤2：门诊工作人员登录后台，找到付款记录，引导刷卡或扫码，完成退款。

目前门诊登记台电脑，可同时访问预防接种系统和HIS系统。门诊可根据自身业务情况和人员安排，考虑是否单独开一台电脑，用于退款。

步骤3：受种者或监护人收到退款提醒。

步骤4：预防接种系统收到退款同步，同步支付记录状态为：已退款。

步骤5：退款后，系统会将退款状态同步至【支付单管理】及【当前登记】中

注意事项：按照财务规范，退款后需要在HIS将已开具的发票进行冲红处理。

规则说明

规则1：退款目前支持整单退及单独退

规则2：门诊接种人员需要在退款流程，核对接种状态

如状态变更为已接种，但实际未接种，则允许撤销接种后，在HIS进行退款操作，

如状态变更为已接种，且实际已经接种，则不允许退款。

其他情况跟进实际业务进行灵活调整。

### 5、其他特殊情况

5-1、超时情况，未提交付款前可基于当前登记疫苗信息，重新发起支付。

5-2、登记信息发生变更的情况，重新登记走新的支付流程

5-3、主动关闭情况，未提交付款前可基于当前登记疫苗信息，重新发起支付。

5-4、网络通讯异常，导致数据未同步的情况，联系客服登记处理。

5-5、医保码超时情况，刷新后，重新扫码或插卡。
