# 数据智控-预防接种大屏

*   **菜单路径：数据智控-数据驾驶舱-预防接种大屏**【4月底会对数据智控菜单进行调整，届时菜单结构会发生变化】
    
*   **权限范围：所有省、市、区县疾控；**
    
*   **需求描述：**
    
    *   新增【总览数据】模块
        
    *   新增【当日数据】模块
        
    *   新增【追溯码采集剂次数】模块
        
    *   新增【重档率】模块
        
    *   新增【档案信息未正确采集率】模块
        
    *   新增【档案迁出情况】模块
        
    *   新增【档案失访情况】模块
        
    *   新增【数据申请订正数】模块
        
    *   新增【未及时补录率】模块
        
    *   新增【非实时扫码接种剂次数】模块
        
*   **操作规则说明：**
    
    *   **规则1：不同类型的单位能够查看的数据范围不一致，对应的默认地图层级也不一致。示例：如为省疾控，则看到的是浙江省全省地图，数据默认查看浙江省全省数据；如为市疾控，则看到的是所属地市地区，数据默认查看地市整体数据。如为区县疾控，则看到的是区县地区，数据默认查看区县整体数据。**
        
*   **操作步骤：**
    

**步骤1：登录系统，打开【数据智控】菜单，打开【数据驾驶舱】菜单**

**步骤2：打开【预防接种大屏】，进入大屏页面。**

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/8K4nyepJzxjb5nLb/img/9a017c87-1882-4752-8db7-f78e6c5ee094.png)

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/8K4nyepJzxjb5nLb/img/d9bc4f7f-b00d-4564-a54b-43dd3c45585a.png)

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/8K4nyepJzxjb5nLb/img/aa458bd7-6b78-441b-b953-63d786cd842e.png)

**步骤3：点击【地图】，选中地市，双击，将下钻到下一级维度。大屏中数据也将会同步刷新。**

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/8K4nyepJzxjb5nLb/img/28b0f455-b642-41dc-8f9e-177dc368307c.png)

**步骤4：点击【地图】，空白处，双击，将返回上一级维度。大屏中数据也将会同步刷新。**

**步骤5：鼠标移入数据模块图标内部 ，将展示数据卡片，展示详细数据。**

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/8K4nyepJzxjb5nLb/img/89e1da66-25fa-456f-b0de-629fb9cddc11.png)

**步骤6：鼠标移入模块标题，可查看具体数据统计规则。**

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/8K4nyepJzxjb5nLb/img/d16566ce-0ddc-4644-bb47-f463121c4929.png)
