# 衢州医疗

项目定位：非财政预算的项目管控报销场景

项目适用范围：衢州市本级3家医院（衢州中医院、衢州妇保院、衢州三院）

涉及系统供应商：人事系统-宏景，全面预算系统-仁享，费控报销系统-政采云

涉及浙里报模块：预算管理（第三方）、财政预算指标、支出管理（9+2场景）、支付管理（国库支付+仁享支付）

发布时间：2025年6月30日

#### 一、方案流程概述

![衢州医院3.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/vBPlN5jwNmgY3OdG/img/7712a412-ac47-4653-991f-327a515d0317.png)

##### （1）与第三方的前期准备工作

1、同步第三方（仁享）用户体系：按照单位同步归属的用户工号、用户名称、用户手机号、归属部门等信息至浙里报。

*   每天晚上凌晨同步并刷新一次第三方用户数据
    
*   支持在浙里报手动更新已有用户信息
    
*   注意：第三方新增了用户，当天还未触发同步至浙里报，则会导致无法获取当前用户无法单点登录至浙里报申请单据，建议后台运营支持，手动刷新单位的用户数据
    

| 单位名称 | 仁享单位code | 浙里报单位ID |
| --- | --- | --- |
| 衢州市中医院 | 33080002 | 115005841311 |
| 衢州市妇幼保健院（衢州市妇幼保健计划生育服务中心） | 33080003 | 115005841312 |
| 衢州市第三医院 | 33080004 | 115005841313 |

手动更新用户信息：运营机构→运营管理→单位管理→更新

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/vBPlN5jwNmgY3OdG/img/d4399daa-9b30-4317-a797-a564f2a34e18.png)

2、同步第三方项目预算信息：

*   每天晚上凌晨同步并刷新一次第三方项目预算信息：跟客户沟通是每次报销实时查询，但是为了减少两边的调用，调整为项目信息同步落库至浙里报
    
*   目前第三方直接获取的预算项目没有查看页面：线上的预算项目是需要通过下发填报才能置入
    

3、钉钉用户首次登录浙里报应用

*   未同步钉钉授权用户信息，衢州医院是用第三方用户系统，因此钉钉审批消息触达时没有用户手机号&钉钉ID之间的关系
    
*   建议在给医院培训时，让所有人员从医院钉钉进入到浙里报应用，此时会需要获取手机号完成关联。仅操作1次

##### （2）在浙里报的前期准备工作：

1、浙里报单据设置：百搭表单，注意流程+打印模板之前设置好

| 单据类型 | 单据名称 |
| --- | --- |
| 申请单 | 公务出行、一般事项、公务接待、会议活动、学习培训、办公用品、设备家具、购买服务、通用采购 |
| 报销单 | 公务出行、一般事项、公务接待、会议活动、学习培训、办公用品、设备家具、购买服务、通用采购 |
|  | （百搭单据）劳务费保险单、维修维保保险单 |

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/vBPlN5jwNmgY3OdG/img/053c0472-b93f-4e0b-80de-d4c42282f330.png)

2、支出配置：

所有场景都需要支持：国库支付&仁享支付

3、浙里报审批流设置：指定人员审核，按需配置

4、浙里报设置费控：同“浙江省机关单位”费控管理

5、国库支付银行回单获取授权

因第三方（仁享）需要获取国库打款成功后的回单，需要提前做回单的授权

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/vBPlN5jwNmgY3OdG/img/bba91cbe-0062-456a-9ec3-1ea6dbdfb275.png)

①选择并确定需要获取银行回单的账户

②前往“浙里办票”进行账户授权

③在浙里报列表标记已授权，系统会自动获取将已授权的账户回单关联至对应单据中

6、预算指标分配：

*   使用国库支付时，需要对一体化指标提前分配，支持单位侧和运营后台配置
    
*   医院老师要求我们需要支持自动分配，因此我们后台提前帮他们配置好，即所有场景包含支持使用所有指标，每年年初都需要手动分配好，避免支出时找不到指标
    

*   单位侧设置入口：预算管理→支出场景设置
    

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/vBPlN5jwNmgY3OdG/img/05c2e176-1876-4cc6-b41e-8bc9c79bd699.png)

*   运营后台设置入口：运营机构→实施工具→单位管理→预算管理→关联支出场景
    

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/vBPlN5jwNmgY3OdG/img/976cf8bf-6740-4e5d-b969-d79c1a54c6e1.png)

7、使用专家库：百搭搭建的保险单需要使用专家库，需提前订购应用

入口：运营机构→运营管理→订购应用→机构→编辑订购，勾选“外聘专家库”

专家库维护入口：辅助功能→外聘专家库

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/vBPlN5jwNmgY3OdG/img/3e5f4ac2-6f61-44ac-ab97-754ef45352d5.png)

8、预算项目管理：

*   医院需要财务人员按照各场景使用第三方预算，因此需要在单位管理→预算管理中，勾选预算项目管理的内容
    
*   医院是财务人员选择项目，因此财务支出选择全单位的项目，需要勾选“预算项目跨部门权限”
    

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/vBPlN5jwNmgY3OdG/img/f873fc19-89d7-40f0-a3cd-42771b15bb37.png)

##### （4）报销流程说明：

1、业务员在PC端 医院全面预算入口，点击对应场景跳转至浙里报

![70d90a1612af5c6f392c948fdab48b8.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/vBPlN5jwNmgY3OdG/img/0c1fe821-d8c3-4ad1-b067-460ea4f81520.png)

异常情况：

①从医院的全面预算入口无法跳转至浙里报，报错提示“xxxx“；主要原因可能是今天刚添加的新员工，因晚上浙里报才同步数据，导致浙里报无用户，无法完成单点登录；

——处理方式：报给浙里报运营，运营手动在后台单位侧刷新用户数据

2、在浙里报页面，业务员按需填写申请单和报销单，提交审批

注意：业务员提交时，不需要填写项目信息和支付信息

| 单据类型 | 单据名称 |
| --- | --- |
| 申请单 | 公务出行、一般事项、公务接待、会议活动、学习培训、办公用品、设备家具、购买服务、通用采购 |
| 报销单 | 公务出行、一般事项、公务接待、会议活动、学习培训、办公用品、设备家具、购买服务、通用采购 |
|  | （百搭单据）劳务费保险单、维修维保保险单 |

3、相关人员审批：按照流程对应人员审批

4、财务人员审核：

①财务选择预算项目：预算项目信息调用第三方获取（仁享预算），支出选择全部门的项目信息

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/vBPlN5jwNmgY3OdG/img/231aa0e9-ed10-434d-a352-f097886155d6.png)

②财务选择支付方式：

*   选择国库支付：使用浙里报的国库支付，支付消息通知给仁享，等国库打款成功后再告知仁享（支付成功+国库回单）
    

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/vBPlN5jwNmgY3OdG/img/a6ebabbe-eb0a-40a1-86d6-a68539fce44a.png)

*   选择仁享支付：使用仁享的支付方式，支付请求告知仁享，支付的结果由浙里报主动查询获取
    

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/vBPlN5jwNmgY3OdG/img/83b57b2a-2137-4e65-b2a3-efec538def1b.png)

5、查看支付结果

①国库支付结果查询：

*   国库支付成功：主动获取支付完成结果，获取到回单后，调用仁享接口传递国库支付完成+国库回单
    
*   国库支付失败：支持重新支付或是驳回，仅驳回需要告知仁享（撤回之前提交预算扣减信息），重新支付不需要调用仁享
    

②仁享支付结果查询：

*   仁享支付结果，间隔5分钟主动查询更新状态；7天后若支付状态仍然是“支付中”，则不再自动查询，需要财务去财务管理->出纳结算->手动同步单据，即再调用仁享接口查询结果
    
*   仁享侧会保证支付成功，浙里报不需要处理支付失败的情况
    

6、钉钉审批消息

医院审核人员收到钉钉审批消息，用户点击钉钉的审核消息，进入浙里报钉钉应用

7、自动生成凭证和归档

国库支付和仁享支付接口，由仁享完成自动归档，我们需要保证国库支付侧的结果和字段同步推送至仁享即可
