## 一、系统概述

发票平台是数字化支撑体系中的核心发票服务模块，为上层业务系统提供统一的发票开具、管理、查询能力。该模块为后台服务/配置模块，无浙里报前端菜单对应，通过 API 接口对外提供服务。

## 二、核心功能

### 1. 发票开具

- 支持增值税电子普通发票、增值税电子专用发票等多种发票类型
- 发票开具接口：接收业务系统请求，调用税控设备开具发票
- 批量开票：支持批量开具多张发票

### 2. 发票管理

- 发票库存管理：监控发票库存余量，低库存预警
- 发票查询：按发票号码、开票日期、抬头等条件查询
- 发票红冲：支持发票红冲操作

### 3. 发票推送

- 开票成功后自动推送发票给用户（短信、邮件等）
- 对接浙里报等业务系统，发票数据自动回传

### 4. 税号管理

- 购方税号校验和自动补全
- 税号变更管理
