## 一、系统概述

收费平台是数字化支撑体系中的核心收费服务模块，为上层业务系统提供统一的收费、支付、对账能力。该模块为后台服务/配置模块，无浙里报前端菜单对应，通过 API 接口对外提供服务。

## 二、核心功能

### 1. 收费管理

- 支持多种收费场景配置（一次性收费、周期性收费、按量收费等）
- 收费项目管理和费率配置
- 收费单据生成和管理

### 2. 支付集成

- 对接微信支付、支付宝、银行转账等多种支付渠道
- 支付状态实时查询和回调处理
- 支持退款、部分退款等逆向操作

### 3. 对账管理

- 自动对账：与支付渠道进行日终对账
- 差异处理：标记和处理对账差异
- 对账报表：生成对账结果报表

### 4. 账单管理

- 账单生成和推送
- 账单查询和导出
- 电子发票关联
