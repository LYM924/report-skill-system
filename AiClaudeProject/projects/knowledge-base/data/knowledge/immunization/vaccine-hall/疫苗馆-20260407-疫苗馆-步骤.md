# 二、【疫苗馆】疫苗供需监测2期-新增【疫苗库存监测预警】

**需求描述：①新增【疫苗库存监测预警】功能，支持短缺预警、均衡性预警、囤积预警3个指标的监控；②支持按照地区进行筛选；③支持按照疫苗大类进行数据筛选；④支持按照省-市-区县-门诊，进行库存监测数据下钻；⑤支持省、市、区县、接种门诊，差异化预警规则，支持自定义配置预警规则阈值。**

**菜单路径：疫苗馆-疫苗供需监测-疫苗库存监测预警**

**影响范围：省疾控、市疾控、区县疾控、接种门诊**

# 三、【疫苗馆】疫苗供需监测2期-损耗相关报表功能优化

**需求描述：①疫苗信息字段调整：增加疫苗类目字段、按六分类进行展示**、**增加疫苗大类名称**、**隐藏疫苗名称字段**、**隐藏规格字段、删除进苗数（瓶）—合计、出苗数-接种用苗数-本级；②筛选条件中，新增疫苗类目字段，支持按照类目进行筛选，筛选的条件=疫苗大类+疫苗小类，支持一级、二级选择。③字段修改，销毁数修改为：报废数。④数据聚合为大类进行统计，不再按照原有的次类进行统计。**

**菜单路径：疫苗馆-报表-免规疫苗及配套注射器使用情况**

**影响范围：省疾控、市疾控、区县疾控、接种门诊**

**界面交互说明：**

**步骤1：打开免规疫苗及配套注射器使用情况报表，查看数据。**

**注意：调整后，列表数据按照大类名称进行聚合展示。**

# 四、【疫苗馆】疫苗供需监测2期-首页增加预警信息展示

**需求描述：①疫苗馆首页增加监测预警模块，主要预警范围包含以下3类：短缺预警、均衡性预警、囤积预警。②支持点击跳转至监测预警管理页面，并携带查询条件进行查询。**

**菜单路径：疫苗馆-首页**

**影响范围：省疾控、地市疾控、区县疾控、门诊；**

**规则说明：①点击可跳转至【疫苗库存监测预警】功能页面，并自动查询某种触发预警的对应疫苗。②按照当前单位的维度进行预警判定，每一种疫苗触发预警时，将会产生1条有效预警数据。**

**规则说明：同一个疫苗，可触发多个类型的预警。**

**界面交互说明：**

**步骤1：在疫苗馆首页查看监测预警相关指标数据。点击可跳转至疫苗库存监测预警管理页面。**

**注意：需被授权了疫苗供需监测相关功能菜单权限的用户才可查看。**

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/KM7qeobPbp5pWlpj/img/26bb3d68-d2d8-415a-8422-003eb825123a.png)

**步骤3：点击蓝色疫苗字体，可按照省级-地市级-区县级-门诊级，进行下钻查看。**
