# 一、疫苗供需监测2期-新增【疫苗合同执行率】功能

**需求描述：①新增【疫苗合同执行率】功能，仅浙江省疾控、宁波市疾控可使用；②支持按年度、疫苗、月份进行筛选；③进入页面时默认当年数据、全部疫苗、所有月份；④支持导出。**

**菜单路径：疫苗馆-疫苗供需监测-年度合同执行率**

**影响范围：本期，仅开放试点的疾控可进行使用。**

**规则说明：**

**1、按照合同中已采购入库的疫苗数量/合同约定供应疫苗数量。**

**算法：年度合同执行率=当年疫苗累计已执行合同数/当年疫苗合同数**

**注意：当年累计已执行合同，仅包含当年度的合同。**

**计算公式：疫苗采购数:查询年度中该疫苗的采购入库数**

**注意：月度合同执行率为累计计算，非每个月的执行率。**

**2、首年上线时，往年合同数，手动录入**

**浙江省数据、宁波市数据**

**3、本功能模块仅浙江省疾控、宁波市疾控可使用。其他地区无此功能权限。**

**4、往年剩余合同数，如被执行，则会逐步变化减少直至全部执行完成。**

**5、注意事项：已采购入库的疫苗如发生退苗、退厂，不影响已合同执行疫苗数量及执行率的计算。**

**界面交互说明：**

**步骤1：打开【疫苗供需监测】-【年度合同执行率】**

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/v9kqDejPQ0j5aOVx/img/fb0145b9-c609-47c9-8906-b46bfafeb251.png)

**步骤2：通过筛选条件，筛选不同年度、疫苗、数据范围，并查看数据。**

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/v9kqDejPQ0j5aOVx/img/d038acef-c8d1-48c6-a0be-85d7118ce5f6.png)

**步骤3：点击【导出】按钮，导出当前查询条件下的数据。**

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/v9kqDejPQ0j5aOVx/img/5d9e2399-4e15-460d-80b8-39313734ff67.png)

**步骤4：导出成功，查看已导出的数据内容。**

# 三、疫苗供需监测2期-通过年度使用计划自动创建疫苗采购计划

**需求描述：①创建年度采购计划时，可通过已完成的年度使用计划，自动生成免规疫苗采购计划。②**

**菜单路径：疫苗馆-疫苗采购计划管理-国家免规疫苗采购计划**

**影响范围：仅浙江省疾控可使用**

**规则说明：**

**\*仅审核通过的年度使用计划，可被关联采购计划。**

**\*年度使用计划中，非疫苗类的的将会自动过滤：注射器+PPD**

**\*自动带入疫苗次类对应的疫苗采购计划中疫苗数量**

**界面交互说明：**

**步骤1：打开【疫苗采购计划管理】-【国家免规疫苗采购计划】**

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/v9kqDejPQ0j5aOVx/img/416163a5-93ef-4226-980e-cbbeef414add.png)

**步骤2：点击【新增】，选择计划年度，选择关联的年度使用计划批量添加。点击确定。**

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/v9kqDejPQ0j5aOVx/img/1d1239a5-562f-40db-8f56-b9b22a042ff9.png)

情况1：采购计划已存在，无法添加。

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/v9kqDejPQ0j5aOVx/img/114b639a-ef45-4e5a-9715-edba39a0cd2c.png)

情况2：采购计划部存在，可正常添加。

**步骤3：自动带出匹配到的疫苗类型，未匹配到的将会在页面中提示。**

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/v9kqDejPQ0j5aOVx/img/6dfc73f7-02bc-4bd1-8b07-e4010e7d2216.png)
