# 2025-12-25

【数字化门诊】鸿蒙一体机问题修复+稳定性提升

【问题修复】校园流感相关问题修复

【疫苗真实世界研究平台】功能优化

【预防接种】国外疫苗补录功能：国外疫苗DTwP-HepB-Hib，从种类DTaP/IPV/Hib移除，单独作为一个种类进行选择。

# 一、【数字化门诊】鸿蒙一体机问题修复+稳定性提升

**需求描述：①已知的兼容性导致的设备无法使用的问题修复。②设备稳定性提升，包含程序稳定性及网络连接稳定性提升。**

**菜单路径：无**

**权限范围：所有使用此设备的接种门诊**

**规则说明：无特殊逻辑**

# 二、【疫苗真实世界研究平台】功能优化

**需求描述：①权限问题优化；②项目立项后，环境处理交互优化。③数据任务处理交互优化。④项目过程优化。⑤账号名称展示优化。⑥停用启用二次确认优化。⑦结项处理功能优化。⑧项目时间范围、数据时间范围逻辑优化。⑨项目时间对项目状态控制逻辑优化。**

**菜单路径：疫苗真实世界研究平台**

**权限范围：已开通权限的单位**

**规则说明：无**

# 三、【问题修复】校园流感相关问题修复

**需求描述：①活动二维码无法动态生成问题优化；②数据明细无法打开问题优化；③新建活动问题优化，解决创建活动后，无法正常参与的问题。**

**菜单路径：便民服务-疫苗活动-校园流感**

**权限范围：已开通校园流感区县范围**
