# 一、【智能预检】义乌项目-智能预检（二期）

**需求描述：①增加历史问答对话查看及管理功能；②针对于智能问答的结果，增加语音播报、赞、踩、复制功能。可通过图标，快捷操作。③增加智能问答回答结果所引用文件内容展示。④针对疫小盾智能体答复的内容，增加【AI生成免责声明】提示。⑤支持进入浙里接种时，自动判定是否存在触发智能预检状态的疫苗预约记录，如存在，则弹窗提示，注意：绑定多个档案、多条预约的，任一满足条件的均会触发。⑥支持根据不同的智能预检结果，引导用户咨询门诊、取消预约、修改预约时间。⑦支持短信及站内信通知。**

**菜单路径：浙里办（支付宝/浙里办）-浙里接种-疫小盾**

**影响范围：试点门诊范围内的，符合条件的浙里接种账号。**

# 二、【智能预检】浙里接种疫小盾可见范围控制能力建设

**需求描述：①支持配置疫小盾图标、弹窗，可展示的范围。②配置完成后，用户登录浙里办-进入浙里接种首页时，自动进行判定，是否符合。③完成数据初始化配置，开放试点门诊。**

**菜单路径：预防接种-今日接种-健康询问-人脸注册；预防接种-今日接种-登记管理-人脸注册；**

**影响范围：所有使用签核设备的接种门诊；健康询问流程、登记流程流程；**

**规则说明：**

**①配置方式：支持按照，接种门诊、区县（区县下的所有门诊）、地市（地市下所有的门诊）进行配置。**

**②生效逻辑：浙里接种账号下绑定的档案的现管单位属于配置范围下的接种门诊的。则允许此浙里接种账号查看和使用疫小盾。**

**③判断逻辑：此浙里接种账号下满足条件的档案数需≥1。**

**注意：排除删除、死亡状态之外的所有的档案**

**注意：仅做疫小盾功能入口的限制，不做内部功能模块的限制。智能预约、智能问答、智能预检，均可查看和使用。**

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/oJGq75kgmaaDWlAK/img/c215d5c7-886e-4205-9e3b-f4e0c534d7a4.png)![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/oJGq75kgmaaDWlAK/img/f67e2ef8-db15-4c0b-8167-f872f1ff7ff6.png)

# 三、【数字化门诊】健康询问流程优化；人证核验身份信息脱敏展示。

**需求描述：①健康询问、疫苗登记环节中，如触发健康询问流程时，签核设备展示健康询问问题内容。如健康询问完成或健康询问中断时，签核设备退出健康询问流程；注意：针对预大于18岁女性，健康询问的问题将会多一条【是否怀孕或有可能3个月内怀孕】；②人脸信息注册绑定档案流程中，对姓名、手机号、身份证号进行加密展示；**

**菜单路径：预防接种-今日接种-健康询问-人脸注册；预防接种-今日接种-登记管理-人脸注册；**

**影响范围：所有使用签核设备的接种门诊；健康询问流程、登记流程流程；**

**规则说明：**

**界面交互说明-健康询问提示：**

**步骤1：打开【预防接种】-【健康询问】/【登记管理】，进入健康询问流程。**

**步骤2：签核设备上触发【健康询问提示】**

**步骤3：工作台完成【健康询问】或【终止健康询问】，签核设备上关闭将康询问提示内容。如未进行任何操作，则1分钟后，会自动关闭，回到签核机默认页面。**
