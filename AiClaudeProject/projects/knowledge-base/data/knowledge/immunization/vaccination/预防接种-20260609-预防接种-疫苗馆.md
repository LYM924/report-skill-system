## 1. 背景与目标

### 背景

原系统使用“国外补录”表述，但实际业务中存在香港、澳门、台湾地区接种记录需要补录的情况。继续将港澳台接种记录归入“国外补录”存在表述不准确及政治风险，因此需要统一调整为“非内地接种记录补录”，并明确区分国外接种、港澳台接种。

### 目标与交付内容

*   将原“国外补录”入口、页面标题、接种历史标签统一调整为“非内地接种记录补录”。
    
*   补录页面增加或调整“接种区域”字段，下拉项为“国外接种”“港澳台接种”。
    
*   补录页面展示非内地接种记录相关温馨提示，明确不上传国家平台、影响智推/逾期提醒/入学入托查验/纳入接种率统计。
    
*   浙里接种电子预防接种证同步使用新展示口径。
    

## 2. 用户、权限与入口

| 用户/角色 | 描述 |
| --- | --- |
| 接种单位门诊老师 | *   新增非内地接种补录记录<br>    <br>*   查看补录记录详情 |
| 受种者/监护人 | *   浙里接种-查看电子预防接种证/接种记录 |

## 3. 场景与功能规则

### 场景一：补录国外或港澳台接种记录

*   触发入口：门诊医生进入原“国外补录”入口。
    
*   页面名称：统一展示为“非内地接种记录补录”。
    
*   用户操作：选择接种区域，录入疫苗、接种日期、接种单位等补录信息。
    
*   接种区域：下拉选择“国外接种”“港澳台接种”。
    
*   系统规则：保存为非内地补录记录，不上传国家免疫规划信息系统。
    
*   数据影响：参与免疫程序智推、逾期未种提醒、入学入托查验、纳入接种率统计。
    
*   温馨提示：
    
    *   目前支持录入的非内地接种疫苗清单。
        
    *   非内地接种疫苗补录记录不上传国家免疫规划信息系统。
        
    *   非内地接种疫苗补录记录影响免疫程序智推、逾期未种提醒、入学入托查验、纳入接种率统计。
        
    *   如需录入清单外的非内地接种疫苗，请联系上级疾控中心。

### 场景二：查看非内地补录记录

*   触发入口：接种历史、接种记录详情、浙里接种电子预防接种证。
    
*   展示规则：原“国外补录”标签统一展示为“非内地接种记录补录”。

# 2. 【预防接种】本省重档合并规则优化，支持外省迁入个案参与。

## 1. 背景与目标

### 背景

跨省数据互联互通后，外省迁入个案逐渐增多。本省重档合并中，部分档案包含外省录入接种记录。原合并逻辑未充分保护外省录入记录，可能在合并过程中出现删除、取消或被同剂次记录覆盖的情况，进而导致合并后数据无法上传国家平台。

### 目标与交付内容

*   支持带“外省迁入”标签，且现管理单位已归本省的正常档案参与本省重档合并。
    
*   将本省重档合并按外省录入记录情况拆成三类：均无外省记录、单边存在外省记录、双边均存在外省记录。
    
*   单边存在外省记录时，强制含外省记录档案作为主档，并锁定外省录入接种记录。
    
*   双边均存在外省记录时，前端拦截合并并引导提交需求工单。
    

## 2. 用户、权限与入口

| 用户/角色 | 描述 |
| --- | --- |
| 接种单位门诊医生 | *   个案编辑保存后触发重档校验<br>    <br>*   档案管理 - 重卡合并 |
| 数据订正处理人员 | *   需求工单的处理 |

## 3. 场景与功能规则

### 场景一：仅一份档案存在外省录入记录

*   触发条件：参与合并的两份本省档案中，仅一份存在外省录入接种记录。
    
*   主档规则：系统默认将含外省录入记录的档案设为主档，主档单选按钮置灰禁用。
    
*   操作提示：用户尝试切换主档时提示“含外省录入记录，默认作为主档案保留。”
    
*   接种记录规则：含外省录入记录档案中的外省录入接种记录行默认强制勾选，复选框置灰不可取消。
    
*   覆盖限制：外省录入接种记录不可被另一档案同剂次记录覆盖。

*   ![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/J9LnW6j1gxeNQlvD/img/2e345911-0054-4c6a-b88a-33eeea73d46c.png)
    

### 场景二：仅一份档案存在外省录入记录，且此外省录入记录在本省存在扫码接种记录

*   弹窗文案：参与合并的2个个案均存在外省录入单位的接种记录，暂不支持合并。请提交需求工单，由专人协助处理。
    
*   工单跳转：弹窗中的“需求工单”支持点击跳转。
    
*   工单预填：
    
    *   标题：本省重档合并失败
        
    *   需求类型：数据订正 / 预防接种
        
    *   内容描述：档案含外省录入数据，不可修改；对应剂次为省平台扫码接种记录，无法合并。疑似外省误录信息，建议提交**需求工单**，由我方对接外省删除记录，亦可自行联系外省处理。涉及接种记录：乙肝 1（接种日期）、脊灰疫苗 1（接种日期）……
        
*   结果口径：门诊端不可自行完成合并，需由专人通过工单协助处理
    
*   ![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/8K4nyeZox3zA0nLb/img/81218538-db5b-47ae-97d8-b6a2f68898c1.png)
    
*   ![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/8K4nyeZox3zA0nLb/img/7ec70312-c298-4c2d-83c8-f7291ddcca1a.png)
    

### 场景三：两份档案均存在外省录入记录

*   触发条件：参与合并的两份本省档案均存在外省录入单位的接种记录。
    
*   系统规则：前端拦截合并请求，中断合并流程。
    
*   弹窗文案：参与合并的2个个案均存在外省录入单位的接种记录，暂不支持合并。请提交需求工单，由专人协助处理。
    
*   工单跳转：弹窗中的“需求工单”支持点击跳转。
    
*   工单预填：
    
    *   标题：本省重档合并失败
        
    *   需求类型：数据订正 / 预防接种
        
    *   内容描述：参与合并的2个个案均存在外省录入单位的接种记录，暂不支持合并。个案1:xxxxxxxxxx；个案2:xxxxxxxxxx；
        
*   结果口径：门诊端不可自行完成合并，需由专人通过工单协助处理。

# 3. 【预防接种】跨省优化：当不满足跨省要求但本省存在已合并档案时，引导还原本省档案接种。

## 1. 背景与目标

### 背景

跨省重档个案中，存在主档案已被本省迁入、对方省份合并正常且 UUID 一致性校验通过，但该个案未通过省级平台前置校验的情况。原逻辑会引导新建档案，没有优先引导还原本省已有档案，影响不必要档案的新增。

### 目标与交付内容

*   跨省业务无法正常进行，且省平台已存在合并状态档案时，引导还原本省档案进行接种。
    

## 2. 用户、权限与入口

| 用户/角色 | 描述 |
| --- | --- |
| 接种单位门诊医生 | 跨省迁入、跨省不迁入时触发 |

## 3. 场景与功能规则

### 场景：存在跨省重档组或合并记录，跨省系统校验不通过

*   触发条件：系统查询到个案存在跨省重档组或合并记录，跨省系统校验不通过。
    
*   系统规则：**不再引导新建档案**，改为**引导还原本省档案**。
    
    *   页面标题：非重档恢复申请。
        
    *   页面内容：该档案未通过省级平台前置校验，无法进行跨省接种业务；系统查询到省内已有档案与之合并，请还原本省原档案后开展接种业务。
        
    *   页面按钮：取消、确认。
