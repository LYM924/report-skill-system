# 2025年12月11日发布

**需求单号：260805【公司上浙里报】借款链路闭环**

关注人员：公司使用，温岭国投，需要使用预借款的客户

需求实现：未选

一、使用场景1：（公司使用场景）先申请“预借款”，在通过“员工报销”关联预借款

1、百搭单据-预借款报销单：

*   设置好报销总金额的字段编码，已关联单据字段的报销总金额的字段编码保持一致（可关联单据赋值）
    

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/ZWGl05mvxrmB5n34/img/9898e490-ccae-4b0f-b69f-1448c0d2dbb2.png)

2、百搭单据-员工报销单

设置可关联百搭的单据，此时关联之前的“预借款”单据，系统会自动置入预借款金额

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/ZWGl05mvxrmB5n34/img/48793cc4-439d-42fe-a6ed-cbf020bb1e4b.png)

设置后台：

*   关联单据：设置需要关联的”场景类型“=”预借款申请“；勾选“赋值当前单据”，注意一定要保持前后单据的字段编码保持一致，则可赋值
    
*   赋值的计算规则：点击整个单据，所有“数字”组件的都可作为计算变量并设置加减规则，比如本次报销金额=单据总金额-预借款金额
    

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/ZWGl05mvxrmB5n34/img/0d6c38b9-0b4e-4fb7-b3ae-ac68defad253.png)

*   发票信息组件：可配置校验，发票总金额≥预借款金额+本次报销金额
    
*   预算项目组件：可配置校验，预算金额=预借款金额+本次报销金额
    

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/ZWGl05mvxrmB5n34/img/1ac59ae3-c278-45a5-890d-1feb6956e691.png)

二、使用场景2：（温岭国投）充值扣费场景，按照结算单发起报销单0元

1、预先给电力或是手机卡充值了，充值时没有线上付款单据，按月结算时需要记录金额，但是报销金额=0

2、百搭报销单-0元报销单：设置好结算金额和本次报销金额，比如11月结算金额1k，本次报销金额0元

**需求单号：262442和262441 百搭和固定场景都增加主动催办的能力**

关注人员：衢州医疗，所有单位

需求实现：提交单据人员，可主动催签（提交人催下一个审批人）

支出管理-我的单据，单据提交人，查看单据详情页，PC和H5端都增加“催签”按钮，可主动触发钉钉或是浙政钉的审批消息，提醒当前阶段的审批人去审核

*   百搭场景：全部支持，所有百搭单据的提交人都允许手动催签
    

注意：因钉钉和浙政钉的催办消息限制每人每天仅支持催1次，若二次催办浙里报也会提示用户无法催办

**需求单号：264204 【衢州医疗】收款账户别名的支行未传递问题**

关注人员：衢州医疗

需求实现：固定场景的收款账户，在单据中创建或是主动选择收款账户，单据仅使用别名大行传递给一体化或是支付渠道，会导致用户维护的必填支行无法传，因此针对衢州的仁享支付，增加处理逻辑，有支行信息，则传递支行，没有支行则传递别名

**三、262317【六公建设】百搭-票据信息-增加允许后补发票配置**

需求实现：针对因公出国（境）场景，用户报销时未获取发票，此时填写报销单无法上传所有发票，因此针对票据信息组件增加一个“允许后补发票”的配置，开启改配置后，用户在报销单内上传发票时可勾选后补发票，勾选后不检验发票的必填。

注意：请在发票配置为必填的情况下再打开发票后补功能，否则未上传发票的单据都会流转到财务。

用户勾选发票后补后，单据提交并审核完成，此时需要后补的单据将流转到【财务管理-发票补充】菜单内，由财务人员来进行发票补充。

四、**262318【六公建设】百搭-文件上传-增加允许后补附件配置**

需求实现：针对因公出国（境）场景，用户报销时经费决算表、护照等附件信息，此时填写报销单无法上传所有附件，因此针对文件上传组件增加一个“允许后补附件”的配置，开启改配置后，用户在报销单内上传附件时可勾选后补附件，勾选后不检验该附件的必填。

注意：请在发票配置为必填的情况下再打开附件后补功能，否则未上传附件的单据都会流转到财务。

用户勾选附件后补后，单据提交并审核完成，此时需要后补的单据将流转到【财务管理-发票补充】菜单内，由财务人员来进行附件补充。
