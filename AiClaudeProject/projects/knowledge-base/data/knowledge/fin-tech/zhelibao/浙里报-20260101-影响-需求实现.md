# 2025\_11月发布说明

# 2025年11月04日发布

**需求单号：261278【同程商旅】火车票调整为自动开具**

影响：在浙里报商旅平台预订火车票，从手动开票调整为同程自动开票

需求实现：从浙里报跳转至同程火车票预订界面，通过同程商旅的订单同步接口传递开票信息，同程侧同步开通火车票自动开具能力，订单行程完成后自动开具发票，浙里报通过查询接口获取发票（11月底会优化成同程主动推送）

# 2025年11月11日发布

**需求单号：261875【同程商旅】火车票预订界面增加跨单位限制**

需求实现：在火车票下单页面，根据出行人是否是外部人员增加校验，若存在跨单位的人员，则需要删除外部或是其他单位，保证是同单位使用一个开票抬头，否则不允许订单

**需求单号：260416 【收款账户】凭票创建收款账户优化**

影响：宁波地区影响会大，目前每周都会接到宁波打款失败，本期主要优化凭票创建收款账户的落库逻辑，提升打款成功率，减少问题工单

需求实现：一般事项报销时，上传发票后，收款账户入口将增加【凭票添加账户】入口，拆分对应的字段，保证大行和支行落库准确

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/1GXn45Kj95RWkqDQ/img/8fd53554-2866-4a95-b860-f526f58e43fb.png)

**需求单号：260798【公司上浙里报】供应商账户组件优化**

影响：公司上浙里报的对公账户报销场景，账户处理优化，加强供应商账户管理，减少收款账户问题

需求实现：

1、创建采购合同（百搭）：调整单据

该申请单搭建时增加“收款账户”组件，自定义设置收款账户是个人还是企业、是选择还是创建；设置好后，业务员将会按照设置的情况，在收款账户信息中显示创建或是选择的按钮

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/1GXn45Kj95RWkqDQ/img/2ba29711-cc2b-4323-8a98-9deeca8bfa02.png)

申请单选择收款账户：

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/1GXn45Kj95RWkqDQ/img/a98ec0b0-11b5-4092-a9f0-ecac7628c18b.png)

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/1GXn45Kj95RWkqDQ/img/fdaec9b0-5131-4689-8848-4f33417349aa.png)

2、对公付款报销单（百搭）：调整单据

报销单的单据中增加收款账户组件，并建立与申请单的关系；当报销单关联申请单后，自动置入申请单的收款账户，并页面标记“来源：关联单据”，减少财务核对的成本

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/1GXn45Kj95RWkqDQ/img/8efa7908-deb6-4196-9c16-2b91a5f0b747.png)

**需求单：260946【嵊州医疗】功能优化和完善**

影响：嵊州市中医院，以及使用新的预算填报的单位（可设置填报单位计算公式的）

需求方案：

1、使用新的预算填报时，允许追加追减和调剂

2、预算模板预览和展示列表顺序调整：按年下发填报预算时是1个年度值，按季度是4个值，对应的前后比较需要跟着对应季度，比如2025年第一季度和2024年第一季度比较，并展示同比增减

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/1GXn45Kj95RWkqDQ/img/fac20fdd-1913-45ce-99ff-41ac23a79982.png)

3、预算模板下发时若字段缺失，直接当前页面补充，减少页面切换

*   预算依据字段缺失：当预算依据的历史数据=下发前补充，补录后，预算依据的历史数据=固定值，数值=填入的值
    
*   预算科目字段缺失：同预算依据
    
*   模板的填报科目字段缺失：预算科目，填写方式仍然=发起方填写，数值=填入值；年度下发，则仅补录1个值，若是季度则需要有4个值，月度为12个值
    
*   模板的填报依据的科目字段缺失：同上
    

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/1GXn45Kj95RWkqDQ/img/2351eca7-2238-41d2-a084-37b61e6ff78d.png)

260795 【衢州医疗】报销凭证推第三方

260796 【温附二】报销凭证推第三方

影响：衢州医疗和温附二，以及未来需要使用第三方的OSS上传凭证业务

需求实现：

原本报销单审核完成后，请求第三方支付，本期新增文件获取的链路

①文件采集：收集报销单中的文件数据，比如有10个文件，则告知给获取了10个文件的内部文件地址

②文件上传至第三方：接受到文件采集成功后，调用第三方的文件上传接口，上传成功后得到对方的文件file，请求支付时透传文件file。

——目前若因为文件采集或是调用第三方文件上传失败而中断的情况，不阻塞请求第三方支付链路，后期优化增加补推凭证的连接（待第三方提供接口）
