# 技术支持周报生成系统 · 使用文档

> 版本：v2.0 | 更新：2026-08-06

---

## 一、系统概述

翡翠技术支持周报一键生成系统，自动从 Confluence 和本地 Excel 拉取数据，审计核对后生成标准化周报，并支持一键发布到 Confluence。

### 核心能力

- 自动识别当前周次和日期范围（周五→周四）
- 5 路并行数据获取（Excel + Confluence × 4）
- 20 项自动审计（数据完整性、四舍五入、趋势一致性等）
- Markdown → Confluence 格式自动转换（嵌套列表、表格、链接）
- 一键发布到 Confluence（自动创建或覆盖更新）

## 二、环境准备

### 2.1 安装依赖

```bash
pip install openpyxl beautifulsoup4
```

### 2.2 配置环境变量

```bash
export CONFLUENCE_TOKEN="your_bearer_token"
```

**获取 Token**：联系管理员获取 Confluence 个人访问令牌。

### 2.3 放入数据文件

将 `技术支持工单明细.xlsx` 放入数据目录：

```bash
cp 技术支持工单明细.xlsx projects/report-system/data/
```

Excel 文件查找优先级：`--excel 参数 → 环境变量 → data/ → 旧路径(兼容)`

## 三、快速开始

### 3.1 一键生成 + 发布

```bash
cd projects/report-system/weekly-report/

# 步骤1：查看本周数据摘要
python3 weekly_data.py --summary

# 步骤2：运行审计检查
python3 weekly_data.py --audit

# 步骤3：生成报告（由 Claude Code 完成）
# 告诉 Claude："生成本周周报"

# 步骤4：发布到 Confluence
python3 weekly_data.py --publish
```

### 3.2 指定周次

```bash
python3 weekly_data.py --week W30 --summary   # 查看 W30 数据
python3 weekly_data.py --week W30 --audit     # 审计 W30 数据
python3 weekly_data.py --week W30 --publish   # 发布 W30 周报
```

## 六、审计检查项

`--audit` 共执行 20 项检查：

| 类别 | 检查项 | 严重度 |
|------|--------|:--:|
| 业务指标完整性 | 4 个业务组数据是否齐全 | error |
| 两小时完结率 | 四舍五入取整 + 达标判断 | warning |
| 故障一致性 | 故障数据与业务指标交叉验证 | info |
| 超期工单排除 | 附录1 排除"外部超时" | error |
| 需求过滤 | 排除"已完成"状态 | error |
| 趋势标注 | ▲/▼/— 与数据变化一致 | warning |

**审计通过标准**：0 个 error。

## 十、常见问题

### Q1: Excel 文件找不到？
```
❌ Excel 文件不存在: projects/report-system/data/技术支持工单明细.xlsx
```
**解决**：将 Excel 文件放入 `data/` 目录，或通过 `--excel` 指定路径。

### Q2: Confluence Token 失效？
```
❌ Confluence 数据获取失败
```
**解决**：重新设置 `export CONFLUENCE_TOKEN="..."` 。

### Q3: 审计有 warning？
```
完结率取整: 96.49% 需四舍五入取整为 96%
```
**解决**：生成报告时手动取整，或在简述中写 96%（自动取整后的值）。

### Q4: 发布时找不到本地文件？
```
❌ 本地周报文件不存在
```
**解决**：先让 Claude Code 生成周报 `.md` 文件，再执行 `--publish`。

### Q5: Confluence 上已有同名页面？
```
找到已有页面: 285670455 (版本 9)
更新已有页面 (版本 9 → 10)...
```
**说明**：自动覆盖，无需手动删除旧页面。

## 十一、周定义

- **一周**：上周五 → 本周四
- **周次**：从年初第一个周五开始计数（2026-01-02 为 W1）
- **自动检测**：`weekly_data.py` 根据当前日期自动计算，无需手动输入
