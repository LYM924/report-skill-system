# 技术支持周报 - 最终结果输出

## Overview

本 skill 负责将已审计确认的数据填充到周报模板中，生成最终报告。仅在 `tech-support-weekly-report-data-audit` 技能的数据审计全部通过后执行。

**输出路径**: `projects/report-system/output/周报/{周次}-技术支持周报.md`

> **路径规则**：所有报表（周报、月报、年报、其他报表）统一保存在 `projects/report-system/output/` 目录下的对应子文件夹中，**禁止**每次新建日期目录。

## 八、输出流程

1. 确认报告周期（本周起止日期）
2. 按本 skill 模板结构，将 `tech-support-weekly-report-data-audit` skill 审计确认后的数据逐项填入
3. 对比上周数据，标注趋势（▲/▼/—）
4. 按两小时完结率 ≥ 95% 达标标准，判断各业务组达标/不达标（**注意：必须先四舍五入取整后再判断**）
5. **【最终自检】检查所有两小时完结率是否已四舍五入取整**，确认简述和各附录中的值均不保留小数位
6. 输出文件到 `AiClaudeProject/{日期}_报表管理系统/周报/{周次}-技术支持周报.md`
