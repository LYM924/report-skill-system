# 数据文件目录

## 使用说明

将以下原始数据文件放入此目录：

### 必需文件

| 文件名 | 说明 | 获取方式 |
|--------|------|---------|
| `技术支持工单明细.xlsx` | 技术支持工单明细数据 | 从客服系统导出（每周更新） |

### 目录结构

```
报表管理系统/
├── data/                          ← 数据文件目录（本目录）
│   ├── README.md                  ← 本说明文件
│   └── 技术支持工单明细.xlsx       ← 放在这里
├── weekly-report/
│   ├── weekly_data.py             ← 一键数据获取脚本
│   └── SKILL.md                   ← 周报生成 Skill
└── monthly-report/
    └── ...
```

### 文件格式要求

`技术支持工单明细.xlsx` 需包含以下列（按顺序）：

| 列 | 内容 | 示例 |
|----|------|------|
| A | 工单编号 | 202607290917595869120 |
| C | 二级部门 | 数智财务组 |
| D | 三级部门 | 浙里报 |
| E | 模块 | 票据管理 |
| F | 问题分类 | 功能问题 |
| G | 提交时间 | 2026-07-29 09:17:59 |
| K | 是否超时 | 是/否 |
| L | 超期原因 | 开发超时 |
| N | 工单摘要 | 用户反馈发票验真失败... |
| P | 备注 | ONCALL链接: https://... |

### 配置方式

脚本按以下优先级查找 Excel 文件：

1. 命令行参数 `--excel /path/to/file.xlsx`
2. 环境变量 `WEEKLY_REPORT_EXCEL_PATH`
3. `./data/技术支持工单明细.xlsx`（推荐，本目录）
4. 原始路径（兼容旧版）
